## 1. Digital Systems and Information

### 1.1 数字信号

- 模拟信号连续；数字信号离散。
- 二进制用两个电平表示 0/1，抗噪声能力强。
- HIGH/LOW 与 true/false、1/0 的对应不是天然唯一；一般正逻辑约定 HIGH = true = 1。
- 输入通常“宽进严出”：输入端对 HIGH/LOW 的可接受范围更宽，输出端要求更严格。
- 中间浮动区 undefined，不能当作稳定 0 或 1。

### 1.2 抽象层

从上到下：

1. Algorithms
2. Programming Languages
3. Operating Systems
4. Instruction Set Architecture
5. Microarchitecture
6. Register Transfers
7. Logic Gates
8. Transistor Circuits

数逻主要连接 register transfer、logic gates、transistor circuits：上接体系结构，下接硬件电路。

### 1.3 进制转换

整数部分：除基取余，倒序写。  
小数部分：乘基取整，顺序写。

二、八、十六互转：

- 1 位八进制 = 3 位二进制。
- 1 位十六进制 = 4 位二进制。

> [!example] 题型
> `529.625` 先转二进制，再按 3/4 位分组得到八/十六进制。

### 1.4 有符号数

以 8 bit 为例：

- 原码：最高位符号位，后 7 位数值。
- 反码：正数同原码；负数符号位不变，数值位取反。
- 补码：正数同原码；负数为反码加 1。

补码范围：

$$
-2^{n-1}\sim 2^{n-1}-1
$$

8 bit 为 `-128` 到 `127`。

### 1.5 编码

8421 BCD：

- 每一位十进制数用四位二进制表示。
- BCD 加法若结果大于 9 或产生进位，加 `0110` 修正。

Excess-3：

- 在 8421 BCD 基础上加 3。

Gray code：

- 相邻码字只差一位。
- 二进制转 Gray：最高位不变，其余位为相邻二进制位异或。

奇偶校验：

- 偶校验：包含校验位后，1 的总数为偶数。
- 奇校验：包含校验位后，1 的总数为奇数。
- 题目说校验位放左边，就把 parity bit 放最高位一侧。

## 2. Combinational Logic Circuits

### 2.1 逻辑运算和逻辑门

- AND：全 1 才 1。
- OR：有 1 就 1。
- NOT：取反。
- XOR：不同为 1。
- NAND/NOR：通用门。

常用律：

- 吸收律：$A+AB=A$，$A(A+B)=A$。
- 德摩根：$(AB)'=A'+B'$，$(A+B)'=A'B'$。
- 对偶原则：交换 $+$ 与 $\cdot$，交换 $0$ 与 $1$，恒等式仍成立。
- 一致性定理：$XY+X'Z+YZ=XY+X'Z$。

### 2.2 minterm / maxterm

minterm：

- 每个变量出现一次。
- 对应真值表中输出为 1 的行。
- 用 $\Sigma m(\cdots)$ 表示。

maxterm：

- 每个变量出现一次。
- 对应真值表中输出为 0 的行。
- 用 $\Pi M(\cdots)$ 表示。

同一函数中，minterm 下标集合和 maxterm 下标集合互补。

### 2.3 SOP / POS

- SOP：sum of products，乘积项相加。
- POS：product of sums，和项相乘。
- canonical SOP/POS：每项包含全部变量。
- SOM：sum of minterms。
- POM：product of maxterms。

从真值表写表达式：

1. 输出为 1 的行写 minterm，相 OR。
2. 输出为 0 的行写 maxterm，相 AND。

### 2.4 成本

Gate input cost：

- 统计逻辑门输入端数量。
- 是否计 NOT 看题目定义。

GN：

- gate input cost with NOTs。
- 在 G 基础上加反相器输入成本。

做法：先画化简后的电路，再数门输入，不要只看表达式长度。

### 2.5 K-map

规则：

- 圈 1 得最简 SOP。
- 圈 0 得最简 POS。
- 圈大小为 $1,2,4,8,\dots$。
- 圈越大越好，可以重叠。
- 边界相邻，四角相邻。
- don't care 可按有利于化简取 0 或 1。

进阶概念：

- implicant：覆盖若干 1 的圈。
- prime implicant：不能继续扩大的圈。
- essential prime implicant：至少覆盖一个只有它能覆盖的 1。

> [!warning] Hazard
> 多路径延迟不同可能造成毛刺。K-map 中增加冗余圈有时能消除静态冒险。

## 3. Combinational Logic Design

### 3.1 设计流程

1. 明确输入、输出和功能。
2. 写真值表或行为描述。
3. 得到布尔表达式。
4. 化简。
5. 选择实现：门、MUX、decoder、PLA/PAL。
6. 验证：真值表或仿真。

层次化设计：用 adder、decoder、MUX、register 等功能块搭复杂系统。

### 3.2 技术参数

- fan-in：一个门可接受的输入数量。
- fan-out：一个输出可驱动的输入数量。
- propagation delay：输入变化到输出稳定的时间。
- contamination delay：输入变化到输出开始变化的最短时间。
- transition time：信号从低到高或从高到低的转换时间。

组合电路总延迟看最长路径；一条路径穿过多个门时，总延迟近似为各级门延迟相加。

### 3.3 MUX 实现函数

二选一 MUX：

$$
Y=S'I_0+SI_1
$$

四选一 MUX：

- 两个 select 决定 $I_0,I_1,I_2,I_3$。
- 若用 $A=S_1,B=S_0$，固定 $AB$ 后看剩余变量 $C$，每个 $I_k$ 通常是 `0/1/C/C'`。

步骤：

1. 选变量做 select。
2. 固定 select 的每种组合。
3. 看剩余变量下函数值。
4. 填 data input。

### 3.4 Decoder / Encoder

Decoder：

- $n$ 输入，$2^n$ 输出。
- 每个输出对应一个 minterm。
- 实现函数时，把需要的 minterm OR 起来。

Encoder：

- $2^n$ 输入，$n$ 输出。
- priority encoder 处理多个输入同时为 1。

### 3.5 PLA / PAL / ROM

| 器件 | AND 阵列 | OR 阵列 |
|---|---|---|
| PLA | Programmable | Programmable |
| PAL | Programmable | Fixed |
| ROM | Fixed decoder | Programmable OR |

### 3.6 算术逻辑电路

半加器：

$$
S=A\oplus B,\qquad C=AB
$$

全加器：

$$
S=A\oplus B\oplus C_{in}
$$

Carry look-ahead：

$$
G_i=A_iB_i,\qquad P_i=A_i\oplus B_i
$$

$$
C_{i+1}=G_i+P_iC_i
$$

CLA 用并行进位减少 ripple carry 的串行等待。

## 4. Sequential Circuits

### 4.1 组合 vs 时序

组合电路：

$$
Output=F(Input)
$$

时序电路：

$$
NextState=F(State,Input)
$$

输出：

- Mealy：$Output=F(State,Input)$。
- Moore：$Output=F(State)$。

> [!warning] 真题点
> “output 是关于 state 和 input 的函数”对应 Mealy。

### 4.2 Latch 和 Flip-Flop

- latch：电平敏感。
- flip-flop：边沿触发。
- SR：注意非法状态。
- D：$Q^+=D$。
- T：$Q^+=T\oplus Q$。
- JK：$Q^+=JQ'+K'Q$。

### 4.3 时序电路分析

给电路，分析步骤：

1. 写触发器输入方程。
2. 用触发器特性方程写 next-state equation。
3. 列 state table。
4. 画 state diagram。
5. 根据输出方程判断 Mealy/Moore。

### 4.4 状态机设计

1. 定义状态含义。
2. 画状态图。
3. 写状态表。
4. 状态编码。
5. 根据触发器类型写激励表。
6. 化简 next-state 和 output。
7. 画电路。

### 4.5 Counter

- Mod-n counter：计数 $0$ 到 $n-1$，到 $n$ 时清零。
- 同步清零：时钟边沿生效。
- 异步清零：clear 信号到达马上清零。

Module 7 计数器：重点看题目要求检测 `111` 还是提前检测 `110`。

### 4.6 时序延迟

setup 约束看最长路：

$$
T_{clk}\ge t_{pcq}+t_{pd,comb}+t_{setup}
$$

hold 约束看最短路：

$$
t_{ccq}+t_{cd,comb}\ge t_{hold}
$$

## 5. Digital Hardware Implementation

### 5.1 SRAM / DRAM / ROM

| 类型 | 特点 |
|---|---|
| SRAM | 快、不需刷新、面积大、常用于 cache |
| DRAM | 密度高、需刷新、速度较慢、常用于主存 |
| ROM | 非易失，读为主 |

### 5.2 延迟题

- propagation delay 看最坏情况。
- contamination delay 看最早变化。
- 多级门电路延迟按路径累加。
- CLA 比 ripple carry 快，因为进位不是一级一级等。

## 6. Registers & Register Transfers

### 6.1 RTL

- `R1 <- R2`：R2 内容送入 R1。
- `R1 <- R1 + R2`：加法结果写回 R1。
- `R1 <- sr R1`：右移。
- `R1 <- R1 xor R2`：逐位异或。

多条 microoperation：

- 若题目说顺序执行，前一条结果影响后一条。
- 若题目说同时执行，用原值计算。

### 6.2 Shift

- logical shift：空位补 0。
- arithmetic right shift：最高位补符号位。
- circular shift：移出的位绕回另一端。

## 7. Memory Basics

### 7.1 容量计算

若有 $k$ 条地址线：

$$
地址数=2^k
$$

总容量：

$$
容量=地址数\times 数据位宽
$$

单位：

- 1 Byte = 8 bit。
- 1 KB = $2^{10}$ Byte。
- 1 MB = $2^{20}$ Byte。

### 7.2 芯片扩展

1. 位宽扩展：目标数据位宽 / 单片数据位宽。
2. 字数扩展：目标地址数 / 单片地址数。
3. 芯片数 = 位宽扩展 × 字数扩展。

例：目标 `128MB`，单片 `2M x 8bit`：

- 单片容量 = `2M Byte`。
- 目标 = `128M Byte`。
- 若位宽同为 8 bit，需要 `64` 片。

## 8. Verilog 题

structural model：用门或模块例化。

```verilog
and g1(w1, a, b);
or  g2(y, w1, c);
```

dataflow model：用连续赋值。

```verilog
assign y = (a & b) | c;
```

写题时先给电路图标中间节点，再分别写 structural 和 dataflow。
