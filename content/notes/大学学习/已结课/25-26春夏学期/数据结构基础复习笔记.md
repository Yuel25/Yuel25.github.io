# 数据结构基础复习笔记

资料依据：[本地路径已隐藏]、[本地路径已隐藏] 以及历年期末 HTML/PDF 题。当前笔记按 FDS 期末高频板块整理，目标是快速复习概念题、手算题和代码题。

## 0. 考点地图

| 板块 | 高频题型 | 必记结论 |
|---|---|---|
| 算法分析 | 求复杂度、比较增长率、递推式 | if/else 取较大支；双指针看摊还；$O$ 只是上界 |
| 线性结构 | 顺序表/链表、栈、队列 | 栈管括号/后缀/中转后；循环队列看表示法 |
| 树与二叉树 | 计数、遍历还原、BST、线索树 | $n_0=n_2+1$；BST 中序有序 |
| 堆 | 建堆、Insert、DeleteMin、堆排序 | BuildHeap 是 $O(N)$；堆不是有序数组 |
| 并查集 | 数组表示、按大小/高度合并、路径压缩 | 根位置存负数；近似 $O(1)$ |
| 线段树 | 建树、单点更新、区间查询 | 三种重叠：无/全/部分 |
| 图 | 表示法、拓扑、最短路、MST、DFS 应用 | Dijkstra 不吃负边；MST 路径不等于最短路 |
| 排序 | 各排序过程、空间、稳定性、下界 | 比较排序最坏下界 $\Omega(N\log N)$ |

> [!tip] 刷题顺序
> 先刷树/堆/排序/散列/图的选择判断，再补代码题。FDS 期末很爱考“性质是否一定成立”，不是只考模板。

## 1. 算法分析

### 1.1 渐进记号

- $O(f)$：上界，不超过这个量级。
- $\Omega(f)$：下界，至少这个量级。
- $\Theta(f)$：上下界同阶。
- $o(f)$：严格低阶。

常见增长：

$$
O(1)<O(\log N)<O(N)<O(N\log N)<O(N^2)<O(N^3)<O(2^N)<O(N!)
$$

易错点：

- $O(\cdot)$ 不是实际运行时间，不能说 $O(N)$ 的程序“一定”比 $O(2^N)$ 的程序快。
- 求 if/else 复杂度：判断代价 + 两个分支中较大者，不把两支相加。
- 内层指针不重置时，可能是摊还 $O(N)$，不是机械乘成 $O(N^2)$。
- $\log(N!)=\Theta(N\log N)$。

### 1.2 最大子序列和

同一问题的四种复杂度：

| 算法   | 思路           | 复杂度          |
| ---- | ------------ | ------------ |
| 三重循环 | 枚举左右端点，再求和   | $O(N^3)$     |
| 双重循环 | 枚举左端点，右端点累加  | $O(N^2)$     |
| 分治   | 左半、右半、跨中点取最大 | $O(N\log N)$ |
| 在线算法 | 当前和为负则清零     | $O(N)$       |
|      |              |              |

在线算法核心：

```cpp
int maxSubsequenceSum(const vector<int>& a) {
    int best = 0, cur = 0;
    for (int x : a) {
        cur += x;
        if (cur > best) best = cur;
        if (cur < 0) cur = 0;
    }
    return best;
}
```

负前缀可以丢掉：它只会让后续子序列更小。

### 1.3 二分与递推式

二分查找前提：数组有序。每次折半，所以 $O(\log N)$。

递推式常见形态：

- $T(N)=T(N/2)+O(1)\Rightarrow O(\log N)$。
- $T(N)=T(N/2)+O(N)\Rightarrow O(N)$。
- $T(N)=2T(N/2)+O(N)\Rightarrow O(N\log N)$。
- $T(N)=2T(N/2)+O(1)\Rightarrow O(N)$。

## 2. 线性结构

### 2.1 List ADT

顺序表：

- 随机访问 $O(1)$。
- 删除首元素 $O(N)$，因为要搬移。
- 尾插通常 $O(1)$，若扩容另算。

链表：

- 按值查找 $O(N)$。
- 已持有位置指针时，插入/删除可 $O(1)$。
- 双向循环链表在结点 `p` 后插入 `q`，要改 4 个指针：`q->next`、`q->prev`、`p->next`、原后继的 `prev`。

多项式链表相乘：若非零项数分别为 $N_1,N_2$，两两相乘为 $O(N_1N_2)$。

### 2.2 栈

栈是 LIFO。高频应用：

- 括号匹配：左括号入栈，右括号弹栈匹配。
- 后缀表达式求值：操作数入栈，运算符弹两个数计算后压回。
- 中缀转后缀：操作数输出，运算符按优先级弹栈。

易错点：

- 后缀求值中，先弹出的是右操作数 `b`，后弹出的是左操作数 `a`，减法/除法是 `a-b`、`a/b`。
- 中缀转后缀时，左括号在栈外优先级最高，入栈后优先级最低，只有遇到右括号才弹出。
- 对空栈 `Pop`/`Top` 是 ADT 错误；对满栈 `Push` 是具体实现错误。

括号匹配：

```cpp
bool matched(const string& s) {
    stack<char> st;
    for (char c : s) {
        if (c == '(' || c == '[' || c == '{') st.push(c);
        else if (c == ')' || c == ']' || c == '}') {
            if (st.empty()) return false;
            char t = st.top(); st.pop();
            if ((c == ')' && t != '(') || (c == ']' && t != '[') || (c == '}' && t != '{')) return false;
        }
    }
    return st.empty();
}
```

### 2.3 队列

队列是 FIFO，适合先到先服务、BFS。

循环队列：

- 若用 `front` 和 `rear`，常牺牲一个单元区分空/满，容量为 `m-1`。
- 若额外维护 `size`，容量可为 `m`。
- 若 `front` 指首元素、`rear` 指末元素后一位，长度为 `(rear-front+m)%m`。

## 3. 树与二叉树

### 3.1 基本计数

树的边数：$E=N-1$。

一般树若 $n_i$ 表示度为 $i$ 的结点数：

$$
\sum i n_i = N-1,\quad N=\sum n_i
$$

二叉树常用结论：

- 第 $i$ 层最多 $2^{i-1}$ 个结点，根为第 1 层。
- 高度为 $h$ 的二叉树最多 $2^h-1$ 个结点（高度按层数时）。
- 对任意非空二叉树，空指针数为 $N+1$。
- 若只有度 0 和度 2 的结点，则 $n_0=n_2+1$。

完全二叉树数组下标从 1 开始：

- 父亲：$\lfloor i/2\rfloor$。
- 左孩子：$2i$。
- 右孩子：$2i+1$。
- 结点 $i$ 所在层：$\lfloor\log_2 i\rfloor+1$。

### 3.2 遍历

三种 DFS 遍历：

- 前序：根、左、右。
- 中序：左、根、右。
- 后序：左、右、根。

还原二叉树：

- 前序 + 中序：前序首元素是根，在中序中切左右子树。
- 后序 + 中序：后序末元素是根，在中序中切左右子树。
- 前序 + 后序通常不能唯一确定，除非附加条件。

表达式树：

- 中序得到中缀表达式。
- 前序得到前缀表达式。
- 后序得到后缀表达式。

线索二叉树：

- $N$ 个结点有 $N+1$ 个空指针。
- 中序线索树：左空指针指向中序前驱，右空指针指向中序后继。
- 好处：中序遍历可少用栈/递归。

### 3.3 BST

BST 性质：左子树键值 < 根 < 右子树键值，且左右子树也都是 BST。

结论：

- 中序遍历得到升序序列。
- 查找/插入/删除复杂度为 $O(d)$，$d$ 是目标深度。
- 随机情况下平均 $O(\log N)$，退化成链时最坏 $O(N)$。
- 插入序列接近有序时，BST 容易退化。

```cpp
TreeNode* find(TreeNode* root, int x) {
    if (!root) return nullptr;
    if (x < root->val) return find(root->left, x);
    if (x > root->val) return find(root->right, x);
    return root;
}
```

## 4. 优先队列与堆

优先队列支持 `Insert` 和 `DeleteMin`。二叉堆是满足堆序性质的完全二叉树，通常用数组存。

最小堆：

- 结构性质：完全二叉树。
- 堆序性质：每个结点值不大于孩子值。
- 根是最小值。
- 任意查找仍是 $O(N)$，因为堆只保证父子偏序，不保证全局有序。

操作复杂度：

| 操作          | 方法            | 复杂度         |
| ----------- | ------------- | ----------- |
| `Insert`    | 放末尾，上滤        | $O(\log N)$ |
| `DeleteMin` | 取根，末元素下滤      | $O(\log N)$ |
| `BuildHeap` | 从最后一个非叶结点开始下滤 | $O(N)$      |
| 查找任意键       | 线性扫描          | $O(N)$      |

易错点：

- BuildHeap 是 $O(N)$，不是 $O(N\log N)$。
- 堆排序额外空间可为 $O(1)$。
- 最大堆中最小值一定在叶子层，但具体位置不唯一。
- 堆的中序遍历不一定有序。

## 5. 并查集与线段树

### 5.1 并查集

并查集维护动态等价关系。数组表示：

- `S[x] < 0` 表示 `x` 是根，负数可存集合大小或高度。
- `S[x] >= 0` 表示父结点下标。

两大优化：

- 按大小/高度合并：小树挂大树，或矮树挂高树。
- 路径压缩：`Find` 时把路径上的点直接挂到根。

```cpp
int find(vector<int>& s, int x) {
    return s[x] < 0 ? x : s[x] = find(s, s[x]);
}

void unite(vector<int>& s, int a, int b) {
    a = find(s, a);
    b = find(s, b);
    if (a == b) return;
    if (s[a] > s[b]) swap(a, b); // s[root] 是负 size，越小集合越大
    s[a] += s[b];
    s[b] = a;
}
```

复杂度：按秩合并 + 路径压缩后，均摊 $O(\alpha(M,N))$，实际近似 $O(1)$。

### 5.2 线段树

适用：动态区间查询 + 单点修改。可维护 sum/min/max/gcd 等可结合信息。

三种查询关系：

- 无重叠：返回单位元。
- 完全覆盖：直接返回当前结点值。
- 部分重叠：递归左右子树并合并。

复杂度：

- 建树：$O(N)$。
- 单点修改：$O(\log N)$。
- 区间查询：$O(\log N)$。
- 区间修改需要 lazy propagation。

## 6. 图算法

### 6.1 图表示

| 表示   | 空间       | 适合             |
| ---- | -------- | -------------- |
| 邻接矩阵 | $O(V^2)$ | 稠密图、快速判断两点是否相邻 |
| 邻接表  | $O(V+E)$ | 稀疏图、遍历邻边       |

DFS/BFS 用邻接表时复杂度都是 $O(V+E)$。

### 6.2 拓扑排序

适用：DAG。

Kahn 算法：

1. 统计入度。
2. 入度为 0 的点入队。
3. 每弹出一个点，就删除它的出边。
4. 新入度为 0 的点继续入队。

若输出点数少于 $V$，说明有环。

易错点：

- 有拓扑序不代表拓扑序唯一。
- 拓扑序唯一通常要求每一步入度为 0 的候选点唯一。
- 邻接矩阵呈三角形可以说明某种编号下无环，但不自动说明拓扑序唯一。

### 6.3 最短路径

| 算法       | 适用       | 复杂度提示         |
| -------- | -------- | ------------- |
| BFS      | 无权图最短路   | $O(V+E)$      |
| Dijkstra | 非负权单源最短路 | 不能有负边         |
| Floyd    | 多源最短路    | $O(V^3)$，点少时用 |

易错点：

- Dijkstra 不能处理负权边。
- 有负权环时，最短路无定义。
- MST 中两点路径不一定是原图最短路径。

### 6.4 最小生成树

MST 只针对连通无向加权图。

| 算法 | 思路 | 适合 |
|---|---|---|
| Kruskal | 边按权排序，用并查集避环 | 稀疏图 |
| Prim | 从点集扩展，每次选跨割最小边 | 稠密图 |

结论：

- 边权都不同，则 MST 唯一。
- 边权有重复时，MST 可能仍唯一，但不能保证。
- 若每条边权都加 1，MST 总权增加 $V-1$，不是 $E-1$。

### 6.5 DFS 应用

割点：

- DFS 根是割点，当且仅当它有至少 2 个 DFS 子树。
- 非根 `u` 是割点，当且仅当存在孩子 `v` 满足 `Low[v] >= Num[u]`。

欧拉：

- 无向图欧拉回路：连通且所有点度数为偶。
- 无向图欧拉路：连通且恰有 0 或 2 个奇度点。
- 有向图欧拉回路：弱连通相关条件满足，且每点入度 = 出度。

## 7. 排序

### 7.1 总表

| 排序 | 平均 | 最坏 | 额外空间 | 稳定性 | 高频点 |
|---|---:|---:|---:|---|---|
| 插入排序 | $O(N^2)$ | $O(N^2)$ | $O(1)$ | 稳定 | 逆序对越少越快 |
| 希尔排序 | 依增量序列 | 依增量序列 | $O(1)$ | 不稳定 | 间隔插入排序 |
| 堆排序 | $O(N\log N)$ | $O(N\log N)$ | $O(1)$ | 不稳定 | BuildHeap + 反复 DeleteMax |
| 归并排序 | $O(N\log N)$ | $O(N\log N)$ | $O(N)$ | 稳定 | 迭代归并趟数 |
| 快速排序 | $O(N\log N)$ | $O(N^2)$ | $O(\log N)$ | 不稳定 | 三数取中、小数组插排 |
| 桶/计数排序 | $O(N+M)$ | $O(N+M)$ | $O(M)$ | 可稳定 | 值域小 |
| LSD 基数排序 | $O(P(N+B))$ | $O(P(N+B))$ | $O(N+B)$ | 稳定 | 从低位到高位 |

### 7.2 比较排序下界

基于比较的排序可看成决策树。$N$ 个不同元素有 $N!$ 种排列，因此最坏比较次数：

$$
\Omega(\log(N!))=\Omega(N\log N)
$$

所以纯比较排序最坏不可能突破 $N\log N$。桶排序/基数排序能突破，是因为利用了值域/位数信息，不是纯比较。

### 7.3 快排易错点

- pivot 总取极值时，快排退化为 $O(N^2)$。
- 三数取中可降低已排序输入的退化风险。
- 小数组用插入排序常更快。
- 与 pivot 相等的元素，左右扫描都应停下并交换，避免全相等数组退化。

非递归快排用栈时，栈里压的是子区间边界 `Left, Right`，不是 pivot 值。

## 8. 散列

### 8.1 基本概念

散列表目标：平均 $O(1)$ 查找/插入/删除。

装填因子：

$$
\lambda=\frac{\text{表中元素数}}{\text{表长}}
$$

冲突不可避免，需要冲突处理。

### 8.2 分离链接

每个桶挂链表。

- 平均查找长度与 $\lambda$ 相关。
- 表长不必大于元素数。
- 删除直接从链表删。

### 8.3 开放定址

所有元素都放在表内，冲突后按探测序列找下一个位置。

常见探测：

- 线性探测：`h_i(x)=(h(x)+i)%TableSize`。
- 平方探测：`h_i(x)=(h(x)+i^2)%TableSize` 或 `h(x)±i^2`。
- 双散列：`h_i(x)=(h1(x)+i*h2(x))%TableSize`。

易错点：

- 线性探测有一次聚集 primary clustering。
- 平方探测可缓解一次聚集，但表长通常要取素数，并保持 $\lambda<0.5$ 才有半表保证。
- 开放定址删除要用懒惰删除，不能直接清空，否则会截断后续查找链。
- 插入失败或表过满时再散列，新表通常取约两倍大的素数。
- 线性探测等价于第二散列函数恒为 1 的双散列。

### 8.4 ASL 手算

成功查找 ASL：每个已插入元素查找到自己的探测次数求平均。

失败查找 ASL：从各可能初始地址出发，到遇到空位所需探测次数求平均。

手算步骤：

1. 按给定顺序插入，画表。
2. 给每个 key 标注第几次探测成功。
3. 成功 ASL = 探测次数总和 / key 数。
4. 失败 ASL 不能只看空格数，要按所有初始地址算。

## 9. 复杂度速查

| 结构/操作 | 查找 | 插入 | 删除/更新 |
|---|---:|---:|---:|
| 有序数组 | $O(\log N)$ | $O(N)$ | $O(N)$ |
| 单链表 | $O(N)$ | $O(1)$（有位置） | $O(1)$（有位置） |
| BST 平均 | $O(\log N)$ | $O(\log N)$ | $O(\log N)$ |
| BST 最坏 | $O(N)$ | $O(N)$ | $O(N)$ |
| 二叉堆 | 任意键 $O(N)$ | $O(\log N)$ | `DeleteMin` $O(\log N)$ |
| 分离链接散列 | 平均 $O(1)$ | 平均 $O(1)$ | 平均 $O(1)$ |
| 并查集 | 均摊近似 $O(1)$ | 合并近似 $O(1)$ | 不适用 |
| 线段树 | 区间查询 $O(\log N)$ | 不适用 | 单点更新 $O(\log N)$ |

## 11. 最后提醒

1. 路径长度通常数边，不数点。
2. 高度/深度定义要看题面，有的题把叶子高度定义为 1，有的定义为 0。
3. BuildHeap 是 $O(N)$。
4. 堆只保证父子关系，不保证中序/层序有序。
5. BST 中序有序，堆中序不一定有序。
6. Dijkstra 不处理负权边。
7. MST 的路径不等于最短路。
8. 开放定址删除用懒惰删除。
