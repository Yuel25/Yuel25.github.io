# 动态规划

> [!abstract] 导览
> 本文对应讲义 **lec08**（Lecture 8 动态规划）。讲义开篇就承认这是「期中之前最令人感到噩梦的一章」——DP 不像回溯、分治、贪心那样自然直观，经验与技巧成分很重，但主线稳定：**先把问题拆成可复用的子问题，再写出子问题最优值之间的递推式**。每个问题都要回答四件事：**状态定义**（子问题记哪些信息）→ **转移方程**（枚举最后一次选择）→ **边界与计算顺序**（初值、填表方向）→ **优化**（滚动数组、Knuth 优化、Hirschberg 线性空间）。

## 1. 动态规划的背景

### 1.1 名字的来历（8.1.1）

1966 年 Bellman 在《Science》发表独著的 *Dynamic Programming*。自传 *Eye of the Hurricane* 里交代：1950 年秋他在兰德公司工作，而兰德受雇于空军，空军上司是美国国防部长 Charles E. Wilson——此人对「研究」一词有病态的憎恨。于是 Bellman 要给「多阶段决策过程」起个**数学味不重**的名字：`planning` 不合适就用 `programming`；`dynamic` 形容「多级、时变」，且这个词不可能有贬义。所以「动态规划」一半是数学，一半是躲审查。

> [!tip] 别被名字误导
> `programming` 指**多阶段决策的规划与表格化求解**，不是写代码；`dynamic` 指**决策随阶段推进**，不是「运行期动态分配内存」。

### 1.2 爬楼梯：从分治失败到 DP（8.1.2）

**问题**：爬 $n$ 阶楼梯，每次跨 $1$ 或 $2$ 阶，求走法总数 $f(n)$。组合做法：设有 $k$ 步跨两阶，选出哪 $k$ 步即可，

$$f(n)=\sum_{k=0}^{\lfloor n/2\rfloor}\binom{n-k}{k}$$

**分治尝试**：从中点劈开，$n=2m$ 时按**是否踩到第 $m$ 级**分类——踩到则前后各爬 $m$ 阶任意组合 $f(m)^2$ 种；没踩到则必定从第 $m-1$ 阶跨到第 $m+1$ 阶，两边各爬 $m-1$ 阶，$f(m-1)^2$ 种：

$$f(2m)=f(m)^2+f(m-1)^2,\qquad f(2m+1)=f(m)f(m+1)+f(m-1)f(m)$$

$n=2m+1$ 时复杂度递推 $T(n)=4T(n/2+O(1))+O(1)$，即 $O(n^2)$；而且 $n/2$ 可能是奇数，「两半同规模」的前提会破——分治失败。

**看最后一步（DP）**：到第 $n$ 阶只能从 $n-1$ 跨一级或从 $n-2$ 跨两级：

$$f(n)=f(n-1)+f(n-2)\quad(n\ge2),\qquad f(0)=f(1)=1$$

这就是斐波那契。但直接写递归会严重重复计算：算 $f(n-1)$ 时已算过 $f(n-2)$，返回后又要重算。设调用次数 $C(n)$，则 $C(0)=C(1)=1,\ C(n)=C(n-1)+C(n-2)+1$，**指数级**。两步解决：① 算出就存数组，即**记忆化递归**；② 从 $f(0),f(1)$ 顺着递推自底向上填表，只要答案时用两个变量滚动即可。

```text
算法 8.1  爬楼梯：迭代计算
输入：整数 n ≥ 0
输出：爬 n 阶楼梯的方法数 f(n)
1: if n ≤ 1 then return 1
2: Last ← 1；NextToLast ← 1
3: for i ← 2 to n do
4:     Answer ← Last + NextToLast
5:     NextToLast ← Last；Last ← Answer
6: end for
7: return Answer
```

时间 $O(n)$、空间 $O(1)$。

### 1.3 从计数到最优化：DP 四步（8.1.3）

> [!important] 最优子结构
> 若问题的**最优解**可以由**若干子问题的最优解**按递推关系直接拼出，则称具有**最优子结构性质**；此时用记忆化/迭代求出递推式，就是动态规划。

> [!important] 设计 DP 的四步
> 1. 分析最优解由哪些部分构成，**确定子问题**（状态）；2. 写出子问题最优值间的**递推关系**；3. 给出**初值**并选择**计算顺序**，保证自底向上可算；4. 用保存的信息**恢复一个最优解**。
>
> 1–3 是基础；只要最优值时可省第 4 步。要做第 4 步，通常要在第 3 步额外维护**选择表**（分点、根、前驱、是否选中等）。

> [!warning] 最容易错的是状态定义
> 递推式再漂亮，状态少记一维就是错的。判断标准：**做完一次选择后剩下的子问题需要知道哪些信息，状态就必须记录哪些信息**。背包多「容量」一维（3.2 节）、红黑树计数多「黑高」一维（第 7 节），都是被这条逼出来的。

## 2. 加权独立集合问题

### 2.1 问题与模型（8.2.1）

**打家劫舍**：沿街房屋各有现金，相邻两间有连通防盗系统，同一晚闯入相邻两间会报警，求一夜最高金额。把每间房看成顶点 $v_1..v_n$、相邻连边 $(v_i,v_{i+1})$，图是一条**路径**，现金是权重 $w_i$。**独立集合**指没有两个顶点相邻的顶点子集；目标是**最大加权独立集合**。

**例（讲义图 8.1）**：$w=(1,4,5,4)$。全部 8 个独立集合为：空集、4 个单点集、$\{v_1,v_3\},\{v_1,v_4\},\{v_2,v_4\}$；最优是 $\{v_2,v_4\}$，总权重 $4+4=8$。

两条路被排除：枚举每个点选不选要查 $2^n$ 个子集；从中间分两段，则**分界处相邻两点可能都被选中**，拼起来不合法。

### 2.2 最优子结构：最后一个点选不选（8.2.2）

先做自顶向下的实验：**$v_n$ 在不在最优解里？** 只有知道它才能往前构造。设 $G_i$ 为前 $i$ 个点构成的路径图、$S$ 为最优解：

1. **$v_n\notin S$**：$S$ 是 $G_{n-1}$ 的独立集合，且必须是**最大加权**的——否则换成 $G_{n-1}$ 中更重的独立集合就得到更好的解，与最优矛盾。
2. **$v_n\in S$**：邻点 $v_{n-1}$ 不能选；去掉 $v_n$ 后剩下一组顶点全在 $G_{n-2}$ 中，且必须构成 $G_{n-2}$ 的最大加权独立集合——否则换成更好的解再加上 $v_n$ 也会改进原方案。

两种情形都归约为**更小的同类问题** ⟹ 最优子结构成立。

> [!important] 递推式
> $$W_0=0,\qquad W_1=w_1,\qquad W_i=\max\{W_{i-1},\;W_{i-2}+w_i\}\quad(i\ge2)$$
> **不选 $v_i$ 就继承 $W_{i-1}$；选 $v_i$ 就拿 $w_i$ 并跳过 $v_{i-1}$**。

### 2.3 填表与恢复（算法 8.2 / 8.3）

```text
算法 8.2  路径图最大加权独立集合：填表
输入：顶点 v1..vn，权重 w1..wn ≥ 0
输出：最优值 W[n] 与数组 W
1: W[0] ← 0
2: if n ≥ 1 then W[1] ← w1 end if
3: for i ← 2 to n do
4:     W[i] ← max{W[i-1], W[i-2] + wi}
5: end for
6: return W[n], W
```

上例 $w=(1,4,5,4)$：

| $i$ | 0 | 1 | 2 | 3 | 4 |
|---|:-:|:-:|:-:|:-:|:-:|
| $W_i$ | 0 | 1 | 4 | 6 | 8 |
| 依据 | 初值 | $w_1$ | $\max\{1,0{+}4\}$ | $\max\{4,1{+}5\}$ | $\max\{6,4{+}4\}$ |

只扫一遍、每步常数次运算 ⟹ $\Theta(n)$ 时间、$\Theta(n)$ 空间（留前两项则 $O(1)$）。**恢复（算法 8.3）**：从 $i=n$ 倒着走——$W_i=W_{i-1}$ 说明不选 $v_i$（跳到 $i-1$）；否则最优值来自 $W_{i-2}+w_i$，选中 $v_i$ 并跳到 $i-2$。上例：$8>6$ 选 $v_4$ 跳 2，$4>1$ 选 $v_2$ 跳 0，得 $\{v_2,v_4\}$，$O(n)$。

> [!warning] 相等时方案不唯一
> 代码在 $W_i=W_{i-1}$ 时选「不选」只是约定，选 $v_i$ 同样最优。考题说「恢复一种方案」即可。若允许**负权重**，递推式不变但初值改为 $W_1=\max\{0,w_1\}$。

> [!tip] 一般图与树
> 该递推**对任意图都成立**（选 $v$ 则邻点全禁，不选则删 $v$），但一般图无结构，子问题共 $2^n$ 个（NP 难）；对**树**可做树形 DP：记 $\mathrm{ch}(u)$ 为 $u$ 的孩子集合，则 $I[u]=w_u+\sum_{v\in\mathrm{ch}(u)}O[v]$、$O[u]=\sum_{v\in\mathrm{ch}(u)}\max\{I[v],O[v]\}$，叶子 $I=w_u,O=0$，$O(n)$（习题 8.1）。

### 2.4 例题 8.1：最大子序列和

> [!note] 例题 8.1（最大子序列和）
> 非空数组，求最大和的**非空连续子序列**。用 DP 写递推并求最大和与区间。

**状态设计**：「连续」不好套「前 $i$ 个」，改用**带结尾约束**的状态——$E[i]$ 为**以 $a_i$ 结尾**的最大连续子序列和。以 $a_i$ 结尾的要么只有 $a_i$，要么是某个以 $a_{i-1}$ 结尾的序列再接 $a_i$，后者自然希望前半段尽可能大：

$$E[1]=a_1,\qquad E[i]=\max\{a_i,\ E[i-1]+a_i\}$$

答案取 $\max_i E[i]$；实现时 $e$ 保存 $E[i]$、$start$ 记录当前段起点，扫一遍 $O(n)$。**例**：$a=(-2,11,-4,13,-5,-2)$ 对应 $E=(-2,11,7,20,15,13)$，最大 20，子序列 $(11,-4,13)$。

> [!tip] 为什么「以 $i$ 结尾」比「前 $i$ 个」好用
> 「前 $i$ 个」的最优解可能不在末尾，无法与 $a_{i+1}$ 接续；「以 $i$ 结尾」把「能否接续」**编码进状态**，转移时只需看 $E[i-1]$ 的符号。这是状态设计最常见的技巧。

## 3. 背包问题

### 3.1 问题（8.3.1）

$n$ 件物品，第 $i$ 件重量 $s_i$、价值 $v_i$，容量 $C$；每件**只有一件且整件装入**，即 **0–1 背包**（重量正整数、容量非负整数、价值非负）。**例**：$s=[2,1,3,2]$、$v=[12,10,20,15]$、$C=5$，最优装第 1、2、4 件，价值 $12+10+15=37$。

### 3.2 最优子结构：为什么需要两个参数（8.3.2）

仿照独立集合先定**最后一件物品选不选**：不选则转为「前 $n-1$ 件、容量 $C$」；选则须 $s_n\le C$，放入后**容量变 $C-s_n$**，再从前 $n-1$ 件中选。问题在于：只知道「前 $n-1$ 件的最优价值」不够，还要知道**这是在多大容量下得到的**——选物品会消耗容量，所以子问题必须同时用**物品数**和**可用容量**区分。

记 $V_{i,c}$ 为「前 $i$ 件、总重不超过 $c$」的最大价值。固定选不选第 $i$ 件后，剩余部分必须是对应子问题的**最优解**（否则替换成更好的仍满足容量限制却更值钱，矛盾）。

> [!important] 0–1 背包递推式
> $$V_{i,c}=\begin{cases}V_{i-1,c}, & s_i>c\\ \max\{V_{i-1,c},\;V_{i-1,c-s_i}+v_i\}, & s_i\le c\end{cases}\qquad V_{0,c}=0$$

### 3.3 填表与复杂度（算法 8.5）

```text
算法 8.5  0–1 背包：求最优值
输入：正整数重量 s[1..n]，价值 v[1..n]，整数容量 C ≥ 0
输出：最优值 V[n, C] 与表 V
1: for c ← 0 to C do V[0, c] ← 0 end for
2: for i ← 1 to n do
3:     for c ← 0 to C do
4:         V[i, c] ← V[i-1, c]
5:         if si ≤ c then V[i, c] ← max{V[i, c], V[i-1, c-si] + vi} end if
6:     end for
7: end for
8: return V[n, C], V
```

逐格填表（行 $i$ = 件数，列 $c$ = 容量；加粗格 = 与上一行不同，即「选了第 $i$ 件」）：

| $i$ \ $c$ | 0 | 1 | 2 | 3 | 4 | 5 |
|---|:-:|:-:|:-:|:-:|:-:|:-:|
| 0（无物品） | 0 | 0 | 0 | 0 | 0 | 0 |
| 1（$s{=}2,v{=}12$） | 0 | 0 | **12** | 12 | 12 | 12 |
| 2（$s{=}1,v{=}10$） | 0 | **10** | 12 | **22** | 22 | 22 |
| 3（$s{=}3,v{=}20$） | 0 | 10 | 12 | 22 | **30** | 32 |
| 4（$s{=}2,v{=}15$） | 0 | 10 | **15** | **25** | 30 | **37** |

对照两格：$V_{3,5}=\max\{V_{2,5},V_{2,2}+20\}=\max\{22,32\}=32$；$V_{4,5}=\max\{32,V_{3,3}+15\}=\max\{32,37\}=37$。**复杂度**：$(n+1)(C+1)$ 个表项、每项常数次运算 ⟹ 时间空间均 $\Theta((n+1)(C+1))$，简写 $O(nC)$。

> [!warning] $O(nC)$ 不是多项式时间！
> 输入容量 $2^k$ 时输入的二进制只需 $k+1$ 位，算法却要每行算 $2^k+1$ 项。运行时间是 $n,C$ 的多项式，却可能**随输入位数指数增长**——这叫**伪多项式时间算法**。这正是 0–1 背包的判定版本 NP 完全（见 NP 完全性一讲）。

### 3.4 恢复方案与空间优化（算法 8.6 / 8.7）

**恢复**：从 $V[n,C]$ 回溯——若 $V_{i,c}=V_{i-1,c}$，第 $i$ 件可不选、继续看 $i-1$；若 $V_{i,c}>V_{i-1,c}$，最优值必来自选第 $i$ 件，记录并令 $c\leftarrow c-s_i$。两种情况下标都减一，$O(n)$。上例回溯：$37>32$ 选 4、$c=3$；$V_{3,3}=V_{2,3}$ 跳过；$22>12$ 选 2、$c=2$；$12>0$ 选 1，得 $\{1,2,4\}$。

**空间**：填第 $i$ 行只查第 $i-1$ 行，两行就够；进一步只用一个数组——处理第 $i$ 件时 $A[c]$ 表示「前 $i-1$ 件、容量 $c$」的最大价值：

```text
算法 8.7  0–1 背包的一维实现
输入：同算法 8.5
输出：最优值 A[C]
1: A[0..C] ← 0
2: for i ← 1 to n do
3:     for c ← C downto si do
4:         A[c] ← max{A[c], A[c-si] + vi}
5:     end for
6: end for
7: return A[C]
```

> [!important] 为什么必须从大到小更新
> 更新 $A[c]$ 要用 $A[c-s_i]$。若**从小到大**更新，$A[c-s_i]$ 可能**刚被本轮更新过**（已是「选了第 $i$ 件」的值），再更新 $A[c]$ 就等于**把第 $i$ 件选两次**，0–1 背包被错误解成完全背包。空间降到 $O(C)$、时间不变；但**要恢复方案仍须保存整张二维表**——一维数组只剩当前行，无法判断最优值来自选还是不选当前物品。

### 3.5 几种背包变体（8.3.5）

> [!note] 例题 8.2（完全背包）
> 每种物品可取任意多件。令 $U_{i,c}$ 为「只用前 $i$ **种**、容量 $c$」的最大价值，$U_{0,c}=0$。取一件后**还能继续取同一种**，故第二项用索引 $i$：
> $$U_{i,c}=\max\{U_{i-1,c},\;U_{i,c-s_i}+v_i\}\quad(c\ge s_i)$$
> 时间仍 $O(nC)$；一维实现时**正序**更新（既不限一次，也符合 $U_{i,c}$ 依赖 $U_{i,c-s_i}$ 的次序）。

> [!note] 例题 8.3（有界背包）
> 第 $i$ 种最多取 $b_i$ 件：$V_{i,c}=\max_{0\le k\le\min\{b_i,\lfloor c/s_i\rfloor\}}\{V_{i-1,c-ks_i}+kv_i\}$，逐件枚举需 $O((C+1)(b_i+1))$，总 $O\big((C+1)\sum_i(b_i+1)\big)$。
>
> **二进制分组**：把 $b_i$ 件拆成 $1,2,4,\dots,2^{t-1}$ 件一组、剩余 $r$ 件（$1\le r\le2^t$）一组，每组视为一件新 0–1 物品。前 $t$ 组可组合出 $0\sim2^t-1$ 件，加上最后一组又能组合出 $r\sim r+2^t-1$，两段相接或重叠，正好铺满 $0\sim b_i$。例如 13 件分成 $1,2,4,6$ 四组，可取 5 件（1+4）、9 件（1+2+6）。新物品数 $O(\log(b_i+1))$，总时间 $O\big((C+1)(1+\sum_i\log(b_i+1))\big)$。

> [!note] 例题 8.4（分数背包）
> 物品可切开、取比例 $x_i\in[0,1]$。按**单位重量价值 $v_i/s_i$ 降序**装，放不下时取能容纳的比例后停止，$O(n\log n)$：若还没取完单价高的就先取了单价低的，把后者等重部分换成前者可提高总价值。这是贪心（见 [[贪心算法]] 习题 9.5；0–1 背包**不能**这样贪）。

### 3.6 两个参数的字符串问题（8.3.6）

**子序列**：删去若干字符、保持其余字符先后顺序得到（**不必连续**；连续则叫**子串**）。如 `ace` 是 `abcde` 的子序列，`aec` 不是。

> [!note] 例题 8.5（最长公共子序列 LCS）
> 求 $X=x_1..x_m$、$Y=y_1..y_n$ 的 LCS 及长度。例：`abcde` 与 `ace` 的 LCS 为 `ace`，长 3。

令 $L[i,j]$ 为 $X$ 前 $i$ 个字符与 $Y$ 前 $j$ 个字符的 LCS 长度。比较末字符：若 $x_i=y_j$，存在把这两个末字符匹配的最长公共子序列，剩余部分至多 $L[i-1,j-1]$，故最优值恰为 $L[i-1,j-1]+1$；若不等，至少有一个末字符用不上，分别去掉 $x_i$ 或 $y_j$ 取优：

> [!important] LCS 递推式
> $$L[i,j]=\begin{cases}0, & i=0\text{ 或 }j=0\\ L[i-1,j-1]+1, & i,j>0,\ x_i=y_j\\ \max\{L[i-1,j],\,L[i,j-1]\}, & i,j>0,\ x_i\ne y_j\end{cases}$$

时间 $O(mn)$；恢复时相等就记录该字符并转 $(i-1,j-1)$，否则较大的一侧决定跳过谁（相等任选），$O(m+n)$。只求值时保留相邻两行、让短串对应列下标，空间可降到 $O(\min\{m,n\}+1)$——但**恢复字符要回查更早的行**，所以同时省空间又要恢复答案需第 9 节的 Hirschberg。

> [!note] 例题 8.6（序列对齐）
> 两串中插入空位使它们成为等长两行（保持顺序）。字符对空位代价 $g>0$，字符对 $a,b$ 代价 $\alpha(a,b)\ge0$，求代价最小的对齐。例：$X=$`AGGGCT`、$Y=$`AGGCA`、$g=1$、$\alpha(a,b)=0$（$a=b$）/ 2（$a\ne b$），按 `A G G G C T` / `A - G G C A` 对齐，含 1 个空位与 1 次 `T/A` 错配，总代价 $1+2=3$。
>
> 令 $P[i,j]$ 为 $X[1..i]$ 与 $Y[1..j]$ 的最小对齐代价，最后一列只有三种可能（$x_i$ 对 $y_j$、$x_i$ 对空位、空位对 $y_j$）：
> $$P[i,j]=\min\{P[i-1,j-1]+\alpha(x_i,y_j),\ P[i-1,j]+g,\ P[i,j-1]+g\}$$
> 初值 $P[i,0]=ig$、$P[0,j]=jg$（一端为空时另一串每个字符都要对着空位）。$O(mn)$，恢复 $O(m+n)$。

> [!tip] 区间型 vs 双前缀型
> 矩阵链乘法、OBST、RNA 配对（习题 8.12）用**区间** $[i,j]$ 作状态、按**区间长度递增**填表；LCS、序列对齐、编辑距离用**双前缀** $(i,j)$、按**行优先**填表。先判断属于哪类，计算顺序就定了。

## 4. 矩阵链乘法的计算顺序

### 4.1 问题：加括号决定运算量（8.4.1）

$a\times b$ 乘 $b\times c$ 需 $abc$ 次标量乘法。对 $M_1:10\times20,\ M_2:20\times50,\ M_3:50\times1,\ M_4:1\times100$：

- $M_1(M_2(M_3M_4))$：$50\cdot1\cdot100+20\cdot50\cdot100+10\cdot20\cdot100=125000$；
- $(M_1(M_2M_3))M_4$：$20\cdot50\cdot1+10\cdot20\cdot1+10\cdot1\cdot100=2200$。

同样的矩阵只换顺序就差 **57 倍**，目标是找使乘法次数最少的加括号方式。

### 4.2 最优子结构：枚举最后一次乘法（8.4.2）

背包的「先定最后一件物品」**不能照搬**成「先把前 $n-1$ 个乘完再乘 $M_n$」——那等于规定最后一次乘法只能把 $M_n$ 单独放右边，会漏掉 $(M_1M_2)(M_3M_4)$ 这类顺序。正确的最后一步是：**无论括号怎么加，最后一次乘法总把两段相邻矩阵链的结果相乘**。对 4 个矩阵只有三种分法：$M_1|M_2M_3M_4$、$M_1M_2|M_3M_4$、$M_1M_2M_3|M_4$。

设 $M_i$ 为 $r_{i-1}\times r_i$。对 $M_i..M_j$，若最后在 $M_k$ 后分开，就先分别算 $M_i..M_k$ 与 $M_{k+1}..M_j$，且两段都必须取**各自最优顺序**（否则整体可更优）——最优子结构。两段结果分别为 $r_{i-1}\times r_k$、$r_k\times r_j$，最后相乘需 $r_{i-1}r_kr_j$ 次。

> [!important] 矩阵链递推式
> $$m_{ij}=\begin{cases}0, & i=j\\ \displaystyle\min_{i\le k<j}\left\{m_{ik}+m_{k+1,j}+r_{i-1}r_k r_j\right\}, & i<j\end{cases}$$

### 4.3 按链长递增填表（算法 8.8）

注意**计算顺序与前面不同**：$m_{ij}$ 依赖**更短的区间**，所以要按**区间长度 $len$** 递增，而不是按 $i$ 递增。

```text
算法 8.8  矩阵链最优计算顺序
输入：维度数组 r[0..n]（Mi 为 r[i-1] × r[i]）；n = 0 时返回 0 与空方案
输出：最少乘法次数 m[1, n] 与分点表 K
1: for i ← 1 to n do m[i, i] ← 0 end for
2: for len ← 2 to n do
3:     for i ← 1 to n - len + 1 do
4:         j ← i + len - 1；m[i, j] ← +∞
5:         for k ← i to j - 1 do
6:             q ← m[i, k] + m[k+1, j] + r[i-1]·r[k]·r[j]
7:             if q < m[i, j] then m[i, j] ← q；K[i, j] ← k end if
8:         end for
9:     end for
10: end for
11: return m[1, n], K
```

上例填表（$r=(10,20,50,1,100)$）：

| 链长 | 表项 | 各分点候选值 | 最优 | 分点 |
|:-:|---|---|:-:|:-:|
| 1 | $m_{11},m_{22},m_{33},m_{44}$ | — | 0 | — |
| 2 | $m_{12}$ | $k{=}1$：$10\cdot20\cdot50$ | 10000 | 1 |
| 2 | $m_{23}$ | $k{=}2$：$20\cdot50\cdot1$ | 1000 | 2 |
| 2 | $m_{34}$ | $k{=}3$：$50\cdot1\cdot100$ | 5000 | 3 |
| 3 | $m_{13}$ | $k{=}1$：$0+1000+10\cdot20\cdot1=1200$；$k{=}2$：$10000+0+10\cdot50\cdot1=10500$ | 1200 | 1 |
| 3 | $m_{24}$ | $k{=}2$：$0+5000+20\cdot50\cdot100=105000$；$k{=}3$：$1000+0+20\cdot1\cdot100=3000$ | 3000 | 3 |
| 4 | $m_{14}$ | $k{=}1$：$0+3000+10\cdot20\cdot100=23000$；$k{=}2$：$10000+5000+10\cdot50\cdot100=65000$；$k{=}3$：$1200+0+10\cdot1\cdot100=2200$ | **2200** | **3** |

$K[1,4]=3$ 表示最后在 $M_3$ 后分开，即 $(M_1(M_2M_3))M_4$，与 4.1 一致。**复杂度**：长度为 $len$ 的区间 $n-len+1$ 个、每个试 $len-1$ 个分点，总枚举数 $\sum_{len=2}^{n}(n-len+1)(len-1)=\frac{n^3-n}{6}=\Theta(n^3)$；$m,K$ 各 $O(n^2)$ 项 ⟹ 空间 $\Theta(n^2)$。

**恢复（算法 8.9）**：$K[i,j]$ 已记最优分界，从 $K[1,n]$ 递归展开 `PRINTCHAIN(i,j)`（$i=j$ 输出 $M_i$，否则按 $K[i,j]$ 加括号递归两段），时间 $O(n)$、栈 $O(n)$。若只存 $m$ 不存 $K$，每次要重枚举分点，恢复变 $O(n^2)$——**用一个 $O(n^2)$ 的选择表换 $O(n)$ 的恢复时间**是 DP 恢复的通用套路。

## 5. 最优二叉搜索树

### 5.1 问题与「直觉都不对」的例子（8.5.1）

用 BST 存词典，查找频率差别很大，把常查词放得靠近根能减少平均比较次数。单词按字典序排为 $w_1..w_n$，概率 $p_i\ge0$、$\sum p_i=1$；根深度为 0，查找深度 $d_i$ 的 $w_i$ 需 $d_i+1$ 次比较，目标极小化 $\sum_i p_i(d_i+1)$。

> [!note] 例（讲义图 8.3）
>
> | 键 | break | case | char | do | return | switch | void |
> |---|:-:|:-:|:-:|:-:|:-:|:-:|:-:|
> | $p$ | .22 | .18 | .20 | .05 | .25 | .02 | .08 |
>
> 递归选**概率最大者**为根：期望比较 **2.43**；递归选**字母序中间者**为根（尽量平衡）：**2.70**；最优树：**2.15**。可见「按概率贪心」和「按平衡」都不最优——平衡优化的是**最大深度**，不是**期望比较次数**。

### 5.2 最优子结构：先定根（8.5.2）

与矩阵链类比：矩阵链先定「最后分界」，BST 先定**根**。选 $w_k$ 作根，较小的词必须全在左子树、较大的全在右子树；单词已排序，**每组仍是连续区间**，故同样用两个端点表示子问题。

令 $c_{ij}$ 为用 $w_i..w_j$ 建树的最小期望比较次数。固定 $w_k$ 为根：查找这些词**都要先与根比较一次**，先产生 $\sum_{t=i}^{j}p_t$；$w_k$ 到此结束，其余进入左右子树，还需 $c_{i,k-1}$、$c_{k+1,j}$。

> [!important] OBST 递推式
> $$c_{ij}=\sum_{t=i}^{j}p_t+\min_{i\le k\le j}\left\{c_{i,k-1}+c_{k+1,j}\right\}\qquad(i\le j),\qquad c_{i,i-1}=0$$
> **$\sum p_t$ 是「所有结点都要为根多付一次比较」，只与区间有关、与根无关**，所以能提到 min 外。

### 5.3 填表（算法 8.10）

按**区间长度递增**（同矩阵链）；实现细节：先算前缀和 $S[j]=\sum_{t=1}^{j}p_t$，区间概率和 $S[j]-S[i-1]$ 为 $O(1)$。注意单键区间 $c_{i,i}=p_i$（一次比较），空区间 $c_{i,i-1}=0$。

```text
算法 8.10  最优二叉搜索树
输入：有序互异单词表 w[1..n]，非负权重 p[1..n]；空输入返回 0 与空树
输出：最小期望比较次数 c[1, n] 与根表 root
1: S[0] ← 0
2: for i ← 1 to n do S[i] ← S[i-1] + pi end for
3: for i ← 1 to n+1 do c[i, i-1] ← 0 end for
4: for len ← 1 to n do
5:     for i ← 1 to n - len + 1 do
6:         j ← i + len - 1；c[i, j] ← +∞
7:         for k ← i to j do
8:             q ← c[i, k-1] + c[k+1, j] + S[j] - S[i-1]
9:             if q ≤ c[i, j] then c[i, j] ← q；root[i, j] ← k end if
10:        end for
11:    end for
12: end for
13: return c[1, n], root
```

上例的 $c$ 表（只填 $i\le j$）：

| $i$ \ $j$ | 1 | 2 | 3 | 4 | 5 | 6 | 7 |
|---|:-:|:-:|:-:|:-:|:-:|:-:|:-:|
| 1 | 0.22 | 0.58 | 1.02 | 1.17 | 1.83 | 1.89 | **2.15** |
| 2 | | 0.18 | 0.56 | 0.66 | 1.21 | 1.27 | 1.53 |
| 3 | | | 0.20 | 0.30 | 0.80 | 0.84 | 1.02 |
| 4 | | | | 0.05 | 0.35 | 0.39 | 0.57 |
| 5 | | | | | 0.25 | 0.29 | 0.47 |
| 6 | | | | | | 0.02 | 0.12 |
| 7 | | | | | | | 0.08 |

根表：$root[1,7]=3$（`char`）、$root[1,3]=2$（`case`）、$root[1,2]=1$（`break`）、$root[4,7]=5$（`return`）、$root[4,6]=5$、$root[6,7]=7$（`void`），故最优树为

```text
            char
          /      \
      break      return
         \       /    \
        case    do    void
                      /
                   switch
```

验证深度：`char` 0；`break`、`return` 1；`case`、`do`、`void` 2；`switch` 3，于是 $0.20\cdot1+(0.22+0.25)\cdot2+(0.18+0.05+0.08)\cdot3+0.02\cdot4=2.15$。✓

**复杂度**：$O(n^2)$ 个区间 × 每区间 $O(n)$ 个根 ⟹ $O(n^3)$ 时间、$O(n^2)$ 空间；恢复同矩阵链。

### 5.4 Knuth 优化：$O(n^3)\to O(n^2)$（8.5.3）

填表时每个区间都要把其中每个词试作根，而它的两个较短区间早已算好——能否用**已求出的最优根**缩小枚举范围？

> [!important] 用法（先记结论）
> 区间 $(i,j]$ 的最优根一定落在 $\big[R[i,j-1],\,R[i+1,j]\big]$ 内（含端点）。于是枚举量从「区间长」缩到「两个相邻区间最优根之间」，总时间 $O(n^2)$。

**记号**：为让空区间也能用同一套下标，改用 $(i,j]$ 表示 $w_{i+1}..w_j$，$(i,i]$ 为空、$(0,n]$ 为全部。记 $B[i,j]=c_{i+1,j}$、$W[i,j]=\sum_{t=i+1}^{j}p_t=S[j]-S[i]$，则

$$B[i,j]=W[i,j]+\min_{i<k\le j}\{B[i,k-1]+B[k,j]\}\quad(i<j),\qquad B[i,i]=0 \tag{8.1}$$

> [!important] 定理 8.7（四边形不等式）
> 对所有 $a\le b\le c\le d$：$W[a,c]+W[b,d]\le W[a,d]+W[b,c]$，且 $W[b,c]\le W[a,d]$。
> 第一式左边是两个**相交**区间 $(a,c]$、$(b,d]$，右边是它们的**并**与**交**；第二式说明**扩大区间不会减小权重和**（区间包含单调性）。由 (8.1) 与 $B[i,i]=0$ 定义的 $B$ **也满足**同样的不等式。

**证明思路**：$W$ 满足条件是显然的（扩大区间只增非负项；四边形不等式两边含**相同概率项**，恰好相等）。关键是把它**传递给 $B$**：对 $d-a$ 归纳，设 $(a,d]$ 的最优根为 $w_r$，分 $r\le b$、$r>c$、$b<r\le c$ 三种情形，每种都用「以更优候选根给出上界 + 对更短区间用归纳假设」收尾（第三种再按 $(b,c]$ 的最优根 $s\le r$ 或 $s>r$ 分别抵消公共子树）。

> [!important] 定理 8.8（最优根的单调性）
> 令 $R[i,j]$ 为区间 $(i,j]$ 中**下标最大**的最优根，则 $R[i,j]\le R[i,j+1]\le R[i+1,j+1]$。

**证明**（右端点增加）：固定 $i$，记 $F_j(k)=B[i,k-1]+B[k,j]$；设旧根 $u=R[i,j]$、新根 $v=R[i,j+1]$，反设 $u>v$。两者都是合法候选，由 $B$ 的四边形不等式 $B[v,j]+B[u,j+1]\le B[v,j+1]+B[u,j]$，移项后两边同加 $B[i,u-1]-B[i,v-1]$ 正好凑成 $F$：

$$F_{j+1}(u)-F_{j+1}(v)\le F_j(u)-F_j(v)\le 0$$

右侧 $\le0$ 因 $u$ 是 $(i,j]$ 的最优根；左侧 $\ge0$ 因 $v$ 已在新区间最优。故两边都 $=0$，说明 $u$ 在新区间也最优，但 $u>v$，与「$v$ 是下标最大的最优根」矛盾。左端点方向同理。

> [!warning] 「取下标最大的最优根」不能省
> 若每区间随意挑最优根，单调性不成立：$p_1=p_2=p_3=0$ 时任何树代价都是 0，对 $(0,2]$ 选 $w_2$、对 $(0,3]$ 选 $w_1$，都最优但增加一个词后根反而**左移**。算法 8.10 在代价相等时也更新根（`≤`），正好符合约定。

**优化算法（算法 8.11）**：初值 $B[i,i]=0$、$B[i,i+1]=p_{i+1}$、$R[i,i+1]=i+1$；对每个 $(i,j)$ 只枚举 $k=R[i,j-1]\,..\,R[i+1,j]$，取 $q=B[i,k-1]+B[k,j]+S[j]-S[i]$（相等时更新根）。

**为什么总共 $O(n^2)$**：把**含相同词数** $d\ge2$ 的区间归到一起。区间 $(i,i+d]$ 的枚举次数是 $R[i+1,i+d]-R[i,i+d-1]+1$；下一个区间 $(i+1,i+d+1]$ 的候选根恰从 $R[i+1,i+d]$ 开始，**正好接上前一个的终点**，故求和时中间项**一正一负抵消**：

$$\sum_{i=0}^{n-d}\Big(R[i+1,i+d]-R[i,i+d-1]+1\Big)=R[n-d+1,n]-R[0,d-1]+n-d+1\le 2n$$

只有 $n$ 种长度 ⟹ $O(n^2)$。

> [!tip] 查找失败的概率也能纳入
> $n$ 个键有 $n+1$ 个间隙（最小键前、相邻键间、最大键后），落在间隙的概率为 $q_0..q_n$。它们同样要先与根比较一次，故把权重和改为 $W[i,j]=\sum_{t=i+1}^{j}p_t+\sum_{t=i}^{j}q_t$，递推式不变；新的 $W$ 仍满足四边形不等式与区间包含单调性，**Knuth 优化照样适用**。

## 6. 最短路问题再讨论

### 6.1 全源最短路与负边（8.6 引子）

此前熟悉的是**单源**最短路；本节求**全源**（任意两点距离）。除了轮流以每个点为源跑单源算法，还有 **Floyd–Warshall**：用 DP 一次算出所有点对。本节允许负边，先看 Dijkstra 为何失效。

> [!note] Dijkstra 的负边反例（讲义图 8.4 左）
> $s\to t$ 权 $-2$、$s\to v$ 权 $1$、$v\to t$ 权 $-5$。当前到 $t,v$ 分别为 $-2,1$，Dijkstra **先确定** $t$；但经 $v$ 再到 $t$ 只需 $1-5=-4$。原因是 Dijkstra 依赖「当前最近的点不会再被改进」，有负边时前提不成立。

**负环**：环上边权之和为负。若从源点能到负环、再从环走到目标，则**每多绕一圈就更短**，最短距离根本不存在（图 8.4 右环权 $-2$）。所以负边情形下还要能**检测从源点可达的负环**。

### 6.2 Bellman–Ford（8.6.1）

**思路**：逐步放宽「最多允许几条边」。不走边只能停在 $s$；最多 1 条边检查 $s$ 的出边；最多 2 条边可在前一步结果后再接一条边。令 $D^k[v]$ 为从 $s$ 出发、**至多 $k$ 条边**到 $v$ 的最小权重（到不了记 $+\infty$），$D^0[s]=0$、其余 $+\infty$。

> [!important] Bellman–Ford 递推式
> $$D^k[v]=\min\left\{D^{k-1}[v],\ \min_{(u,v)\in E}\left(D^{k-1}[u]+w(u,v)\right)\right\} \tag{8.2}$$
> 两类路线：沿用至多 $k-1$ 条边的旧路线；或先用至多 $k-1$ 条边到 $u$，再沿 $(u,v)$ 到 $v$。

例（图 8.4 左）：

| $k$ | $D^k[s]$ | $D^k[t]$ | $D^k[v]$ |
|:-:|:-:|:-:|:-:|
| 0 | 0 | $+\infty$ | $+\infty$ |
| 1 | 0 | $-2$ | 1 |
| 2 | 0 | $-4$（$1-5$） | 1 |
| 3 | 0 | $-4$ | 1 |

第 3 轮与第 2 轮全同 ⟹ 已稳定；$n=3$ 时 $D^{n-1}=D^2$ 即答案，无负环。

> [!important] 引理 8.9（所有距离同时稳定）
> 若某 $k\ge0$ 使**对所有 $v$** 都有 $D^k[v]=D^{k+1}[v]$，则继续增加边数也不会改变结果，这些值就是从 $s$ 出发的最短距离。
>
> *理由*：把整轮的值代回 (8.2)，下一轮仍相同，归纳即得。**定理 8.10（检测可达负环）**：$n$ 个顶点时不存在从 $s$ 可达的负环 $\iff$ $D^{n-1}[v]=D^n[v]$ 对所有 $v$ 成立。因为无负环时含环路径不比去环后更短，简单路径最多 $n-1$ 条边。

于是算法在「一整轮无距离改变」时提前结束；否则跑满 $n$ 轮，若第 $n$ 轮还能减小就报告可达负环。

```text
算法 8.13  Bellman–Ford：一维数组实现
输入：有向图 G = (V, E)、源点 s；n = |V|，边权有限
输出：各点距离 d 与前驱 pred；或报告存在从 s 可达的负环
1: d[s] ← 0；其余 d[v] ← +∞；所有 pred[v] ← NIL
2: for k ← 1 to n-1 do
3:     changed ← false
4:     for 每条边 (u, v) do
5:         if d[u] < +∞ 且 d[u] + w(u, v) < d[v] then
6:             d[v] ← d[u] + w(u, v)；pred[v] ← u；changed ← true
7:         end if
8:     end for
9:     if ¬changed then 跳出外层循环 end if
10: end for
11: if 存在边 (u, v)，d[u] < +∞ 且 d[u] + w(u, v) < d[v] then
12:     return「存在从 s 可达的负环」
13: end if
14: return (d, pred)
```

**复杂度**：每轮比较 $n$ 个距离、检查 $m$ 条边 $O(n+m)$，最多 $n$ 轮 ⟹ $O(n(n+m))$。讲义另有二维版（算法 8.12），用表 $P$ 记距离来源（`carry` 或边 $(u,v)$）以便恢复整条路线。

> [!warning] 一维实现 ≠ 按 $k$ 递推
> 一维版在一轮内会**沿刚更新的值继续传播**，故第 $k$ 轮后不保证「至多 $k$ 条边」。这不影响最终正确性与负环判定，但**不能逐轮读出 $D^k$**（习题 8.13）。

> [!tip] 应用：距离向量路由
> 路由器维护「到各目的地的距离估计 + 下一跳」。$A$ 到邻居 $B$ 代价 1、$B$ 说自己到 $t$ 估计 3，则 $A$ 得到经 $B$、估计 $1+3=4$ 的路线，比原记录小就更新。这就是**距离向量方法**，RIP 采用（RFC 2453）。

### 6.3 Floyd–Warshall（8.6.2）

**思路**：先要求**中途不经其他顶点**，再依次允许经过 $1,2,\dots,n$。无负环时去环不变短，只需考虑不重复顶点的路径。令 $D^k[i,j]$ 为从 $i$ 到 $j$、**中途只允许经过 $1..k$** 的最短距离（不含起点终点）；$D^0[i,j]$ 为直接边最小权重、无边 $+\infty$、$D^0[i,i]=0$。

> [!important] Floyd–Warshall 递推式
> $$D^k[i,j]=\min\left\{D^{k-1}[i,j],\ D^{k-1}[i,k]+D^{k-1}[k,j]\right\} \tag{8.3}$$
> 允许经过 $k$ 后，最短路**要么不经 $k$**（沿用旧值），**要么经 $k$**——此时在 $k$ 处分成两段，两段内部顶点编号都小于 $k$，恰是 $D^{k-1}$。

```text
算法 8.14  Floyd–Warshall
输入：顶点编号 1..n，有限边权；允许负边、平行边和自环
输出：距离表 D、分点表 K、负环影响标记 bad
1: 所有 D[i, j] ← +∞，K[i, j] ← NIL；所有 D[i, i] ← 0
2: for 每条边 (u, v) do D[u, v] ← min{D[u, v], w(u, v)} end for
3: for k ← 1 to n do
4:     for i ← 1 to n do
5:         for j ← 1 to n do
6:             if D[i, k] < +∞ 且 D[k, j] < +∞ 且 D[i, k] + D[k, j] < D[i, j] then
7:                 D[i, j] ← D[i, k] + D[k, j]；K[i, j] ← k
8:             end if
9:         end for
10:    end for
11: end for
12: Z ← { k : D[k, k] < 0 }
13: bad[i, j] ← false（所有点对）；for k ∈ Z do 对所有可达 i, j 置 bad[i, j] ← true
14: return (D, K, bad)      ▷ bad[i, j] 为真时该点对答案为 −∞
```

**负环**：更新完仍检查**对角线**，若 $D[k,k]<0$ 说明从 $k$ 绕一圈能使总权减小，于是只要 $i$ 能到 $k$、$k$ 能到 $j$，从 $i$ 到 $j$ 就能越绕越短，用 $bad[i,j]$ 标为 $-\infty$。**恢复路径**：$K[i,j]=k$ 就分别恢复 $i\to k$、$k\to j$ 再接起来；无分点且 $i\ne j$ 取两者间最小权边，$i=j$ 只输出该点。**复杂度** $O(n^3+m)$。

### 6.4 全源最短路的三种做法

> [!important] 复杂度比较
>
> | 做法 | 时间 | 适用 |
> |---|---|---|
> | 每个源点跑一次 Bellman–Ford（一维版） | $O(n^2m+n^2)$ | 允许负边 |
> | **Floyd–Warshall** | $O(n^3+m)$ | 允许负边、可判负环 |
> | 每个源点跑一次 Dijkstra + Fibonacci 堆 | $O(nm+n^2\log n)$ | **仅非负边** |
>
> 对 $m=\Theta(n^2)$ 的稠密图，Floyd–Warshall 把 $O(n^4)$ 降到 $O(n^3)$；对 $m=O(n)$ 的稀疏图，Dijkstra 方案是 $O(n^2\log n)$ 更快。选算法要同时看**边权是否非负**与**图是否稀疏**。

> [!tip] 更前沿的进展（讲义补注）
> 非负边权单源最短路，Dijkstra + Fibonacci 堆为 $O(m+n\log n)$，并顺带按距离排好了序；但问题只要求距离。省去全局排序能否更快？Duan、Mao、Mao、Shu、Yin 2025 年给出确定性 $O(m\log^{2/3}n)$ 算法（STOC 2025 最佳论文），对稀疏图比 $O(n\log n)$ 更小——说明「逐个确定全局最近点」并非唯一出路。堆的实现见 [[二项堆与斐波那契堆]]。

## 7. 红黑树计数

**问题（8.7）**：给定 $N$ 个互不相同的键，能建出多少棵不同的红黑树（形状或颜色不同即不同）？注意**一种树形按中序填入排好序的键就唯一确定键值**，所以只需枚举**树形 + 染色**。

约束照旧：根为黑、NIL 叶为黑、红结点无红孩子、从任一结点到各 NIL 的路径上**黑结点数相同**。

### 7.1 状态：结点数 + 黑高 + 根颜色

一棵树 = 根 + 左右子树，先数小子树再拼起来。但**只知左右结点数不够**：两子树到 NIL 的路径上**黑结点数必须相同**；若接在**红根**下，它们的根还必须是**黑**。故按**结点数、路径黑结点数、根颜色**分别计数。

用 $h$ 记从子树根到 NIL 路径上的**黑色内部结点数**（**含根、不含 NIL**）。令 $B[n,h]$、$R[n,h]$ 为 $n$ 个内部结点、根到 NIL 有 $h$ 个黑结点、根为黑/红的子树数（允许红根，是为了统计能接到更大树中的子树）。

> [!important] 初值与递推
> $$B[0,0]=1,\quad B[0,h]=0\ (h>0),\quad R[0,h]=0\ (h\ge0)$$
> $$B[n,h]=\sum_{a=0}^{n-1}\big(B[a,h{-}1]+R[a,h{-}1]\big)\big(B[n{-}1{-}a,h{-}1]+R[n{-}1{-}a,h{-}1]\big)$$
> $$R[n,h]=\sum_{a=0}^{n-1}B[a,h]\,B[n{-}1{-}a,h]$$
> **黑根自己贡献一个黑结点**，故左右子树参数为 $h-1$（子树根可红可黑，取 $B+R$）；**红根不改变黑结点数**，参数仍为 $h$，但**子树根必须为黑**（否则红-红）。固定 $a$ 后左右任意搭配，方案数相乘，再对所有 $a$ 求和。

### 7.2 上界与填表（算法 8.15）

由 lec02 红黑树的**定理 2.3**（高度界）的证明过程有 $h\le\lfloor\log_2(N+1)\rfloor:=H$，故表只需 $0..H$ 这一维。实现时按 $n$ 从 1 到 $N$ 递增，对每个 $n$ 从 $h=0$ 到 $H$ 累加左右分配，最后取 $\sum_{h}B[N,h]$（算法 8.15）。

**小例验证**：$N=1$ 时 $B[1,1]=1$（一个黑根）；$N=2$ 时 $B[2,1]=2$（黑根 + 左/右一个红孩子）；$N=3$ 时 $B[3,1]=1$（黑根 + 两个红孩子）、$B[3,2]=1$（黑根 + 两个黑孩子），共 2 棵。

**复杂度**：状态 $O(N\log(N+1))$，每状态试 $n$ 种左右分配、常数次加乘 ⟹ $O(N^2\log(N+1))$。红黑树本身的性质见 [[平衡树（AVL · Splay · 红黑树）]]。

## 8. 总结：动态规划的设计方法

**数学规划视角（8.8）**：许多问题要求在约束下求最大/最小值，正是运筹学的内容。0–1 背包可写成整数规划

$$\max\ \sum_{i=1}^{n}v_ix_i\quad\text{s.t.}\quad\sum_{i=1}^{n}s_ix_i\le C,\quad x_i\in\{0,1\}$$

DP 进一步利用了**物品顺序**与**整数容量**。能否高效求解取决于**问题有哪些结构**：有结构就用 DP/贪心/网络流等；没结构只能用通用方法（整数规划求解器、**分支定界**），无法保证多项式时间，或改用近似算法但无法保证最优。

**DP 与分治的区别只在「子问题会不会重复」**：归并排序把数组分两半，两次递归处理**不同区间**，子问题不重叠；矩阵链却要试不同分界，**同一段矩阵链的最优值被反复用到**，所以必须记忆化。

| | 分治法 | 动态规划 |
|---|---|---|
| 子问题 | 互不重叠 | **大量重叠**（要复用答案） |
| 求解方向 | 自顶向下递归 | 记忆化递归或自底向上填表 |
| 典型 | 归并/快排、二分 | 爬楼梯、背包、矩阵链、最短路 |

> [!important] 怎么找状态：先确定一次选择，看还剩下什么
> 剩余问题需要知道哪些信息，状态就记录哪些信息：背包选定物品后**容量改变** ⟹ 加「容量」维；矩阵链确定最后乘法后**要分开算两段** ⟹ 用**区间端点**；红黑树计数要求左右**黑结点数相同** ⟹ 加「黑高」维；最大子序列和要「能接在后面」 ⟹ 加「以谁结尾」。最优子结构的确定技巧性很强，见多了自然有直觉。

## 9. 补充材料：Hirschberg 算法

**动机**：长度 $m,n$ 的串可用 $O(mn)$ 的表求 LCS；只求**长度**时留相邻两行即可，但沿表**找回字符**会用到已丢掉的行。问题：**如何不保存整张表却找出一个具体 LCS？**

**分治**：把 $X$ 分成 $X[1..r]$、$X[r+1..m]$，$r=\lfloor m/2\rfloor$。公共子序列中，在 $X$ 前半段选出的字符一定排在后半段字符之前，它们在 $Y$ 中也保持相同顺序。于是在 $Y$ 中找**分界 $j$**：前半在 $X[1..r],Y[1..j]$ 中匹配，后半在 $X[r+1..m],Y[j+1..n]$ 中匹配。记

$$L[j]=\mathrm{LCSLen}(X[1..r],Y[1..j]),\quad R[j]=\mathrm{LCSLen}(X[r+1..m],Y[j+1..n]),\quad \mathrm{LCSLen}(X,Y)=\max_{0\le j\le n}\{L[j]+R[j]\}$$

选最大的 $j$ 后**分别递归**求这两对子串的 LCS，再按先后连接。**怎样只用 $O(n)$ 空间得到全部 $L[j]$、$R[j]$**：$L[j]$ 是用 $X[1..r]$ 与整个 $Y$ 填表到**第 $r$ 行**的第 $j$ 项，一次填表全得，且只留两行；$R[j]$ 对应 $X$ 后半段与 $Y$ 的**后** $n-j$ 个字符，把两者**同时反转**再填一次同样的表（反转后后 $n-j$ 个字符变成前 $n-j$ 个，LCS 长度不变），记最后一行 $Q$，则 $R[j]=Q[n-j]$。

```text
算法 8.16  返回 LCS 表的最后一行
输入：字符串 U[1..a]、V[1..b]
输出：数组 P，其中 P[t] 是 U 与 V[1..t] 的 LCS 长度
1: function LASTROW(U[1..a], V[1..b])
2:     P[0..b] ← 0，分配 C[0..b]
3:     for i = 1, 2, …, a do
4:         C[0] ← 0
5:         for j = 1, 2, …, b do
6:             if U[i] = V[j] then C[j] ← P[j-1] + 1
7:             else C[j] ← max{P[j], C[j-1]}
8:             end if
9:         end for
10:        交换 P、C 的引用，使 P 保存刚算完的一行
11:    end for
12:    释放 C；return P
13: end function
```

```text
算法 8.17  用分治恢复一个 LCS
输入：字符串 X、Y；另建一个空列表依次保存找到的 LCS 字符
输出：一个 LCS（写入该列表）
1: function HIRSCHBERG(X[1..m], Y[1..n])
2:     if m = 0 或 n = 0 then return end if
3:     if m = 1 then
4:         从左到右找 Y 中第一个等于 X[1] 的字符；若找到，把 X[1] 追加到输出列表
5:         return
6:     end if
7:     r ← ⌊m/2⌋
8:     L ← LASTROW(X[1..r], Y)
9:     Q ← LASTROW(rev(X[r+1..m]), rev(Y))
10:    j ← 使 L[j] + Q[n-j] 最大的最小下标（0 ≤ j ≤ n）
11:    释放 L、Q
12:    HIRSCHBERG(X[1..r], Y[1..j])
13:    HIRSCHBERG(X[r+1..m], Y[j+1..n])
14: end function
```

**复杂度**：一次调用中两次填表处理 $rn+(m-r)n=O(mn)$ 个位置，找最佳 $j$ 另需 $O(n)$；两次递归要填的位置数之和 $rj+(m-r)(n-j)\le\lceil m/2\rceil n\le\frac23 mn$，即每层按 $\le2/3$ 收缩，故时间 $O\big(mn\sum_{k\ge0}(2/3)^k\big)=O(mn)$——**时间不变差**。空间上每次填表只留常数个长 $\le n+1$ 的数组且在递归**前释放**，$O(n)$；递归栈每层常数、深度 $O(\log m)$，辅助空间 $O(n+\log m)$；计入输入输出后总空间 $O(m+n)$。

> [!tip] 序列对齐也有对应的线性空间算法
> 思想完全类似（最优值同样能「前半段 + 后半段」拼接），只是最后一列的三种选择让分界稍复杂，可自行推导。

## 10. 习题与答案要点

> [!note] 习题 8.1（一般图的加权独立集合）
> 对任意无向图 $G$、非负权重 $w_v$，令 $H=G-v$、$K=G-N[v]$（再删 $v$ 的邻点及关联边），设三者最优权重为 $W_G,W_H,W_K$，考虑 $W_G=\max\{W_H,\,W_K+w_v\}$。判断：(1) 对路径图不总对；(2) 对路径图总对、对树不总对；(3) 对树总对、对任意图不总对；(4) 对任意图都对；(5) 对树可给出线性算法；(6) 对任意图可给出线性算法。

**答案：第 4、5 项正确。** 递推**对任意图都成立**（论证同 2.2：不选 $v$ 退化为 $H$ 的最优，选 $v$ 则邻点全禁、退化为 $K$ 的最优）；但一般图的子问题是「剩余顶点导出的子图」，无结构时共 $2^n$ 个子集，只能指数枚举，故 (6) 错。对**树**用树形 DP：记 $\mathrm{ch}(u)$ 为 $u$ 的孩子集合，则 $I[u]=w_u+\sum_{v\in\mathrm{ch}(u)}O[v]$、$O[u]=\sum_{v\in\mathrm{ch}(u)}\max\{I[v],O[v]\}$，叶子 $I[u]=w_u,O[u]=0$，最后取根的两项最大值，$O(n)$。

> [!note] 习题 8.2（零钱兑换）
> 若干面额（每种任意多枚）凑出金额 amount，求最少硬币数与方案，凑不出返回 $-1$。例：$coins=[1,2,5]$、$amount=11$，答案 3（$5+5+1$）。

**要点**：$D[x]$ 为凑出 $x$ 的最少硬币数，若**最后一枚**面额为 $c$，其余要凑 $x-c$：

$$D[0]=0,\qquad D[x]=1+\min_{c\in coins,\ c\le x}D[x-c]$$

$A$ 个金额 × $q$ 种面额 ⟹ $O(Aq+A)$；恢复时记录每个 $x$ 选中的面额并倒推。

> [!note] 习题 8.3（Decode）
> 把 $A..Z$ 编码为 `0`..`25`，给非空数字串，求解码方式数。注意 `0` 单独表示一个字母、两位编码不能带前导零（`07` 只能拆成 `0|7`）。

**要点**：$D[i]$ 为前 $i$ 位的解码方式数。最后一位单独成字母给 $D[i-1]$ 种；若最后**两位**在 $10\sim25$ 之间，还可一起成字母，再加 $D[i-2]$。$O(n)$。

> [!note] 习题 8.4（Maximum Subsequence Product）
> 非空实数数组（含负数、0、绝对值小于 1），求非空连续子序列最大乘积，线性时间。例：$(2,3,0.5,-2,4)$ 答案 6。

**要点**：负号会翻转大小，故同时维护以 $i$ 结尾的最大、最小乘积 $H[i],L[i]$，均从 $a_1$ 初始化；候选集 $\{a_i,H[i-1]a_i,L[i-1]a_i\}$，取最大者为 $H[i]$、最小者为 $L[i]$，$O(n)$。上例 $H$ 依次为 $2,6,3,-1,4$，全局最大 6（子序列 $(2,3)$）。

> [!note] 习题 8.5（生产线调度）
> 产品依次完成 $n\ge1$ 个阶段，每阶段可在生产线 0/1 上任一完成。从线 $\ell$ 的第 $j-1$ 阶段出发，留原线完成第 $j$ 阶段需 $a_{\ell,j}$、换线需 $b_{\ell,j}$（均非负）。(1) 设计 $O(n)$ 算法求最少总用时与最优路线，给出讲义图 8.7 的结果；(2) 若 $n\ge2$ 且规定「第一阶段在线 0 加工的产品，最后一步不能从 0 换到 1」，如何修改？

**要点**：(1) $F[\ell,j]$ 为完成第 $j$ 阶段后位于线 $\ell$ 的最少用时，最后一步只有「留原线」或「从另一条换来」：

$$F[\ell,j]=\min\{F[\ell,j-1]+a_{\ell,j},\ F[1-\ell,j-1]+b_{1-\ell,j}\}$$

初值 $F[0,0]=F[1,0]=0$，答案 $\min\{F[0,n],F[1,n]\}$；图中一条最优路线 $0\to0\to1\to0$，总用时 **7**。

(2) 限制取决于**第一阶段在哪条线**，故状态加一维 $z$：$F[\ell,j,z]$，初值 $F[z,1,z]=\min\{a_{z,1},b_{1-z,1}\}$、$F[1-z,1,z]=+\infty$；$j\ge2$ 时对每个 $z$ 用上述递推；**仅当 $j=n,z=0,\ell=1$** 时删去「从线 0 换来」的候选。答案取所有 $F[\ell,n,z]$ 的最小值，仍 $O(n)$。

> [!note] 习题 8.6（Hand-made Cream）
> $n$ 片面包评分 $a[1..n]$、$m$ 份奶油评分 $b[1..m]$，可跳过材料、每份至多用一次，选出的面包与奶油**数量相同且按顺序配对**，得分为评分之积（可负），求最大总得分与方案（可一对都不选，总分 0）。例：$a=(-1,10,8)$、$b=(10,8,11,9)$，选第 2、3 片与第 1、3 份，得分 $10\cdot10+8\cdot11=188$。

**要点**：与 LCS 同型，看两个序列末项——若 $a_i,b_j$ 都被选中，顺序约束迫使它们配成**最后一对**；否则至少跳过其一。$F[i,j]=\max\{F[i-1,j],F[i,j-1],F[i-1,j-1]+a_ib_j\}$，初值 $F[0,j]=F[i,0]=0$（一边为空无法配对）。时间 $O(nm+n+m)$，恢复 $O(n+m)$。

> [!note] 习题 8.7（回文子串与回文分割）
> (1) 求最长回文**子串**（`babad` 可为 `bab` 或 `aba`）；(2) 把整串分成若干回文子串，求最少切割次数与方案（`aab` 分为 `aa|b`，一刀）。

**要点**：(1) $H[i,j]$ 为 $s[i..j]$ 是否回文，一段连续子串由**两端字符 + 去掉两端的中间部分**决定：

$$H[i,j]=(s_i=s_j)\wedge\big(j-i\le1\ \vee\ H[i+1,j-1]\big)$$

按**子串长度递增**填表（单字符恒真、两字符只需相同），$O(n^2)$ 个区间、每区间常数 ⟹ $O(n^2)$。(2) 用 $H$：$F[j]$ 为前 $j$ 个字符最少分成的段数，最后一段设为 $s[i..j]$（须回文）：$F[0]=0,\ F[j]=\min_{1\le i\le j,\ H[i,j]}\{F[i-1]+1\}$，$O(n^2)$；最少**切割**次数 = 段数 $-1$。

> [!note] 习题 8.8（最长递增子序列）
> 按原顺序选尽可能多的元素使其**严格**递增。例：$(3,1,2,2,4)$ 的答案为 $(1,2,4)$（相等元素不能同选）。设计 $O(n^2)$ DP 并恢复方案。

**要点**：固定**最后选中的元素** $a_i$，$E[i]$ 为以它结尾的 LIS 长度；倒数第二项必须来自某个 $j<i$ 且 $a_j<a_i$，取 $E[j]$ 最大者接上：

$$E[i]=1+\max\big(\{E[j]:j<i,\ a_j<a_i\}\cup\{0\}\big)$$

其中 0 对应「前面没有合适元素、只选 $a_i$」。答案取 $\max_i E[i]$；恢复时用 $prev[i]$ 记倒数第二项下标，从长度最大者沿 $prev$ 回溯。

> [!note] 习题 8.9（钢条切割）
> 长 $n$ 的钢条与价格表 $p_i$（样例 $p=(1,5,8,9,10,17,17,20,24,30)$），求收益最大的切割方案。

**要点**：**先决定卖出的第一段有多长**：$R[j]$ 为长 $j$ 的最高收益，

$$R[0]=0,\qquad R[j]=\max_{1\le i\le j}\{p_i+R[j-i]\}$$

$O(n^2)$。样例 $R[8]=22$（$p_2+R[6]=5+17$）、$R[10]=30$（不切）。与完全背包同型：价格表是「物品」，长度是「容量」。

> [!note] 习题 8.10（Manager of Tasks）
> 机器从时刻 0 起按序处理任务 $1..n$，可分成若干组连续任务。每组先花 $S$ 启动、再依次执行组内任务（任务 $i$ 耗时 $T_i$）；同一组全部完成后才一起算完成时刻；任务 $i$ 成本 = 完成时刻 × 系数 $C_i$。例：$S=1$、$T=(1,3,4,2,1)$、$C=(3,2,3,3,4)$，分 $\{1,2\},\{3\},\{4,5\}$ 总成本 153。求 $O(n^2)$ 算法与方案。

**要点**：$F[i]$ 为任务 $i..n$ **从时刻 0 开始**处理的最小总成本（$F[n+1]=0$）。若第一组是 $i..j$，处理需 $d=S+\sum_{k=i}^{j}T_k$，组内成本 $d\sum_{k=i}^{j}C_k$；剩余任务若从 0 开始最小成本 $F[j+1]$，但它们必须等第一组结束、**完成时刻整体推迟 $d$**，故再加 $d\sum_{k=j+1}^{n}C_k$：

$$F[i]=\min_{i\le j\le n}\left\{F[j+1]+\Big(S+\sum_{k=i}^{j}T_k\Big)\sum_{k=i}^{n}C_k\right\}$$

$O(n^2)$；恢复时同步记录每个 $F[i]$ 的最优分点。上例：$F[4]=4\cdot7=28$、$F[3]=5\cdot10+28=78$、$F[1]=5\cdot15+78=153$。

> [!note] 习题 8.11（完全平方数的和）
> 把正整数 $n$ 写成若干正整数平方之和，最少几项？例：$13=4+9$ 需两项。

**要点**：把平方数当硬币面额即化归习题 8.2，可用面额 $1^2,2^2,\dots,\lfloor\sqrt n\rfloor^2$，$Q[x]$ 为凑出 $x$ 的最少平方数个数：$Q[0]=0$、$Q[x]=1+\min_{1\le t\le\lfloor\sqrt x\rfloor}Q[x-t^2]$。每个 $x$ 至多试 $\sqrt n$ 种 ⟹ $O(n\sqrt n)$。

> [!note] 习题 8.12（RNA 配对）
> 序列 $s[1..n]$（`A,C,G,U`）。只允许 A–U、C–G 配对，每位置至多一对，配对位置间隔至少 4 个位置（$j-i\ge5$），弧线**不能交叉**（不能同时选 $(i,j)$ 与 $(k,\ell)$ 且 $i<k<j<\ell$）。求最大配对数与方案。例：`ACCGGUAGU` 可取 $(1,9),(3,8)$。

**要点**：看**最后位置 $j$**：不配对就只处理 $[i,j-1]$；若 $j$ 与 $k$ 配对（$s_k,s_j$ 可配且 $j-k\ge5$），则 $k$ 左边的位置不能与 $(k,j)$ **内部**位置配对（否则交叉），剩下 $[i,k-1]$、$[k+1,j-1]$ 两段独立求解。$R[i,j]$ 为区间最大配对数（空区间 0），其中 $\mathrm{pair}(s_k,s_j)$ 表示两碱基可配对：

$$R[i,j]=\max\left\{R[i,j-1],\ \max_{\substack{i\le k\le j-5\\ \mathrm{pair}(s_k,s_j)}}\big(R[i,k-1]+R[k+1,j-1]+1\big)\right\}$$

$O(n^2)$ 个区间 × 至多 $n$ 个配对位置 ⟹ $O(n^3)$。恢复：记 $mate[i,j]$ 为与 $j$ 配对的 $k$（不配记 NIL）；区间长 $\le5$ 时无处容纳一对、直接返回，否则按 $mate$ 递归两段，$O(n)$。

> [!note] 习题 8.13（最短路判断）
> 判断并解释：(1) 一维数组实现的 Bellman–Ford，第 $k$ 轮后恰好得到至多 $k$ 条边的最短距离；(2) Floyd–Warshall 的三层循环可任意交换。

**答案：两条都错。** (1) 反例：权重均为 1 的边 $s\to u$、$u\to v$，**按此顺序**扫描——第一条先更新 $d[u]=1$，第二条立即用新值更新 $d[v]=2$，一轮内就得到含两条边的路线。故一维原地实现与按 $k$ 递推的二维实现**行为不同**。(2) 反例：顶点 $1,2,3,4$ 与单位权边 $1\to3,3\to4,4\to2$；若最外层枚举 $i$、中间 $j$、最内层 $k$ 且只执行一轮，计算 $(1,2)$ 时 $D[1,4]$、$D[3,2]$ 都还没求出，$D[1,2]$ 仍为 $+\infty$，之后不会再回头更新，于是漏掉路径 $1\to3\to4\to2$。$k$ 必须最外层，因为它代表「允许的中间顶点集合」逐层扩大。

## 11. 考点速查

1. **DP 四步**：定状态 → 写递推 → 定初值与计算顺序 → 恢复最优解（靠选择表：分点 $K$、根表 $root$、前驱 $pred$、是否选中）。
2. **最优子结构**：大问题最优解可由子问题最优解拼出；**重叠子问题**是 DP 相对分治的额外前提。
3. **爬楼梯**：$f(n)=f(n-1)+f(n-2)$、$f(0)=f(1)=1$；朴素递归指数级；迭代 $O(n)$、两变量 $O(1)$ 空间。分治式 $f(2m)=f(m)^2+f(m-1)^2$ 为 $O(n^2)$ 且会退化，**不是**解法。
4. **加权独立集合**：$W_i=\max\{W_{i-1},W_{i-2}+w_i\}$、$W_0=0$，$\Theta(n)$；一般图 $2^n$（NP 难），树用 $I[u]/O[u]$ 树形 DP $O(n)$。
5. **最大子序列和**：$E[i]=\max\{a_i,E[i-1]+a_i\}$，答案 $\max_i E[i]$，$O(n)$；状态必须带「以 $i$ 结尾」。
6. **0–1 背包**：状态 $(i,c)$，$V_{i,c}=\max\{V_{i-1,c},V_{i-1,c-s_i}+v_i\}$，$\Theta(nC)$，**伪多项式**（$C$ 的二进制位数指数级）。
7. **一维背包**：0–1 **逆序**、完全背包**正序**、有界背包**二进制分组** $1,2,4,\dots$；分数背包按 $v_i/s_i$ 降序贪心 $O(n\log n)$。
8. **LCS**：$x_i=y_j$ 时 $L[i-1,j-1]+1$，否则 $\max\{L[i-1,j],L[i,j-1]\}$，$O(mn)$；空间可降，但恢复要 Hirschberg。
9. **序列对齐**：$P[i,j]=\min\{P[i-1,j-1]+\alpha,\ P[i-1,j]+g,\ P[i,j-1]+g\}$，$O(mn)$。
10. **矩阵链**：$m_{ij}=\min_{i\le k<j}\{m_{ik}+m_{k+1,j}+r_{i-1}r_kr_j\}$，**按区间长度递增**填表，$\Theta(n^3)$（枚举数 $(n^3-n)/6$），空间 $\Theta(n^2)$，恢复 $O(n)$；例 $10,20,50,1,100$ 最优 **2200**、$K[1,4]=3$。
11. **OBST**：$c_{ij}=\sum_{t=i}^{j}p_t+\min_{i\le k\le j}\{c_{i,k-1}+c_{k+1,j}\}$，$O(n^3)$；注意 $c_{i,i}=p_i$、空区间 0；例中最优期望 **2.15**（根 `char`），而「概率最大者为根」2.43、「取中间键」2.70。
12. **Knuth 优化**：前提是 $W$ 有**四边形不等式**与**区间包含单调性**且能传递给 $B$；结论 $R[i,j-1]\le k\le R[i+1,j]$，时间 $O(n^2)$。**必须约定「取下标最大的最优根」**（否则 $p_1=p_2=p_3=0$ 即反例）。
13. **Bellman–Ford**：$D^k[v]=\min\{D^{k-1}[v],\min_{(u,v)}(D^{k-1}[u]+w)\}$，$O(n(n+m))$；全轮不变即稳定（引理 8.9）；判负环看 $D^{n-1}$ 与 $D^n$（定理 8.10）。一维原地版**不能**保证「第 $k$ 轮 = 至多 $k$ 条边」。
14. **Floyd–Warshall**：$D^k[i,j]=\min\{D^{k-1}[i,j],D^{k-1}[i,k]+D^{k-1}[k,j]\}$，**$k$ 必须最外层**；$O(n^3+m)$；负环看 $D[k,k]<0$ 并标 $bad[i,j]$。
15. **全源最短路选择**：稠密图用 Floyd–Warshall $O(n^3)$；稀疏且非负权用「每源点 Dijkstra + Fibonacci 堆」$O(nm+n^2\log n)$；负边只能 Bellman–Ford 系。
16. **红黑树计数**：$B[n,h]$（黑根）、$R[n,h]$（红根），$h$ 为根到 NIL 的黑结点数（含根不含 NIL）；$B[0,0]=1$ 其余 0；$h\le\lfloor\log_2(N+1)\rfloor$；$O(N^2\log N)$；整棵树只取 $\sum_h B[N,h]$。
17. **Hirschberg**：用 $L[j]+R[j]$ 找分界 + **反转技巧**求 $R[j]$；时间仍 $O(mn)$（规模按 $\le2/3$ 收缩），辅助空间 $O(n+\log m)$，总空间 $O(m+n)$。
18. **易错点**：① 一维背包方向；② 矩阵链必须按**长度**递增；③ Floyd 的 $k$ 不能挪到内层；④ 负权下 Dijkstra 失效；⑤ 有负环时距离可能不存在（$-\infty$）；⑥ Knuth 优化前要约定根；⑦ 伪多项式不是多项式。
19. **复杂度汇总**：爬楼梯 $O(n)$；加权独立集合 $\Theta(n)$；0–1 背包 $\Theta(nC)$；LCS/对齐 $O(mn)$；矩阵链 $\Theta(n^3)$ / Knuth OBST $O(n^2)$；Bellman–Ford $O(n(n+m))$；Floyd–Warshall $O(n^3+m)$；红黑树计数 $O(N^2\log N)$；Hirschberg $O(mn)$ 时间 $O(n)$ 空间。
