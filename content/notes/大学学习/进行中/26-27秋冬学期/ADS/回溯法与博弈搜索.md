## 1. 基本思想：暴力搜索与剪枝

**暴力搜索(exhaustive search / Brute Force)**：若问题的解空间**有限**，就逐一检查所有可能性。

- **好处**：保证算法**有效性**——所有可能都被检查过，结果必然正确；
- **问题**：很多问题的搜索空间**极其巨大**，暴力法完全不**有效率**。

**剪枝(pruning)**：多数情况下，可以通过一些判断把**很大一部分**可能的结果排除在正确答案之外。

> [!important] 名字的由来
> 搜索正确答案的过程常被表示成**一棵树**，剪枝就是「剪掉」树上不可能的分支——八皇后问题里能看得很清楚。

> [!note] 整个算法设计部分的两条主线
> 讲义指出，接下来所有算法设计讨论都围绕两个要求：
> 1. **有效性(effectiveness)**：能保证结果正确；近似算法保证结果在**一定近似比**内；随机算法保证**一定概率**内合理；
> 2. **有效率(efficiency)**：运行速度应当快速。
>
> 这与学数据结构时的要求是共通的——数据结构要同时关心「操作是否保持结构和序性质」与「操作是否够快」。

## 2. 八皇后问题

**问题**：在 $8 \times 8$ 棋盘上放八个皇后，要求**任意两个皇后不在同一行、同一列或同一条对角线**上。

### 2.1 表示与搜索空间的缩减

把第 $i$ 行皇后所在的列记为 $x_i$，一个摆法就表示为 $(x_1,\dots,x_8)$。这样表示时**每行恰好放一个皇后**，因此不会出现同行冲突。逐步收紧约束：

| 阶段 | 可能性 | 说明 |
|---|---|---|
| 只看「每行一个」 | $8^8$ | 每个 $x_i$ 有 8 种选择 |
| 加上「不能同列」 | $8!$ | $x_1,\dots,x_8$ 必须互不相同 ⟹ 是 $1,\dots,8$ 的一个**排列** |
| 加上「不能同对角线」 | 更少 | 需要检查 |

> [!important] 对角线冲突的判据
> 第 $i$ 行和第 $j$ 行的两个皇后在同一条对角线上，**当且仅当**
> $$|x_i - x_j| = |i - j|$$
> 因为此时它们相隔的**行数与列数相等**。

### 2.2 搜索树与剪枝

用一棵树表示**逐行放置**的过程：

- **根结点**表示空棋盘；
- 从根出发选一条边 ⟹ 确定第一行皇后的位置；往下走到下一层 ⟹ 确定第二行……
- **深度为 $r$ 的结点**表示前 $r$ 行已经放好；
- 从根走到**深度 8 的叶子** ⟹ 得到一种完整摆法。

> [!important] 剪枝的本质
> 假如前两个皇后已经**在同一条对角线上**，继续放置其他皇后**也无法消除**这个冲突，所以这个结点下面的**所有摆法都不用再检查**。这就是剪枝。

**四皇后实例**（$4! = 24$ 个排列）：设第一行放第 1 列，

- 第二行选第 2 列 ⟹ **立即产生对角线冲突**；
- 第二行选第 3 列 ⟹ 第三行无论选剩下的第 2 还是第 4 列，也都冲突；
- 第二行选第 4 列 ⟹ 第三行只能选第 2 列，但第四行剩下的第 3 列又与第三行冲突。

因此**第一行选第 1 列时无解**。撤回这个选择、把第一行改放到第 2 列，继续搜索就能找到 $(2,4,1,3)$；同理第一行选第 3 列能找到另一个解 $(3,1,4,2)$。

### 2.3 用三个布尔数组做 $O(1)$ 冲突检查

对于 $n$ 皇后，用三个布尔数组分别记录**哪些列**、**哪些从左上到右下的对角线**、**哪些从右上到左下的对角线**上已经有皇后。

考虑格子 $(r,c)$：

| 数组 | 覆盖对象 | 编号方式 |
|---|---|---|
| `col[c]` | 第 $c$ 列 | 直接用列号 |
| `diag1[r - c + n]` | **左上→右下**方向的对角线 | 沿此方向走一格行、列**同时加 1** ⟹ $r-c$ **不变**，用差值区分；差值可能为负，统一 $+n$ 变成 $1..2n-1$ |
| `diag2[r + c]` | **右上→左下**方向的对角线 | 沿此方向 $r+c$ **不变**，直接用它编号 |

> [!note] 实例（$4\times4$ 棋盘）
> 若先把皇后放在 $(1,3)$，则置 `diag1[1-3+4] = diag1[2]` 与 `diag2[1+3] = diag2[4]` 为 `true`，其余为 `false`。接下来尝试第二行：
> - 选 $(2,4)$：查到 `diag1[2-4+4] = diag1[2]` 为 `true` ⟹ 与已有皇后在**同一条左上→右下对角线**上；
> - 选 $(2,2)$：查到 `diag2[2+2] = diag2[4]` 为 `true` ⟹ **另一方向**的对角线冲突；
> - 选 $(2,1)$：`diag1[5]` 与 `diag2[3]` 都为 `false`，第 1 列也没有皇后 ⟹ **可以放置**。
>
> 以后**回溯取走**某个皇后时，再把它对应的两个对角线标记**恢复为 `false`**。

### 2.4 算法：枚举所有解

```text
Queens(r):                     ▷ 前 r-1 行已经合法放置
1:  if r = n + 1 then          ▷ 前 n 行都已放好
2:      输出当前摆法 x[1..n] 的副本
3:      return                ▷ 回到上一层，继续尝试其他位置
4:  for c = 1, 2, …, n do      ▷ 依次尝试第 r 行的各列
5:      a ← r - c + n;  b ← r + c          ▷ 经过格子 (r, c) 的两条对角线编号
6:      if col[c] = false 且 diag1[a] = false 且 diag2[b] = false then
7:          x[r] ← c                       ▷ 在第 r 行、第 c 列放下皇后
8:          col[c] ← true;  diag1[a] ← true;  diag2[b] ← true
9:          Queens(r + 1)                  ▷ 保持当前皇后的位置，继续放后面的皇后
10:         x[r] ← 0                       ▷ 后续摆法已尝试完，取走当前皇后
11:         col[c] ← false;  diag1[a] ← false;  diag2[b] ← false
```

**调用约定**：开始搜索前把 `x[1..n]` 全置 0（表示该行尚未放置），把 `col[1..n]`、`diag1[1..2n-1]`、`diag2[2..2n]` 全置 `false`，再调用 `Queens(1)`。

> [!warning] 这些数组由各层递归**共用**
> 因此**每一层在尝试完一个位置后都必须撤销自己所做的修改**（上面第 10、11 步）。这正是「回溯」二字的含义。

### 2.5 时间分析

**先数搜索树的结点数**。暂不检查对角线、只要求不能同列：

- 第一行 $n$ 种选择；
- 第二行避开已占用的一列，剩 $n-1$ 种；
- 第三行剩 $n-2$ 种……

因此前 $r$ 行的摆法共有 $n(n-1)\cdots(n-r+1) = \dfrac{n!}{(n-r)!}$ 种，对应**深度为 $r$ 的结点数**（深度 0 只有根结点，也符合这个式子）。

实际算法还要检查对角线、会跳过有冲突的摆法，所以**每层访问的结点数只会更少**。把深度 $0$ 到 $n$ 各层相加，实际访问的结点总数 $N$ 满足

$$N \le \sum_{r=0}^{n}\frac{n!}{(n-r)!} = n!\sum_{j=0}^{n}\frac{1}{j!} < 3\,n!$$

最后一个不等式用到：当 $j \ge 2$ 时 $j! \ge 2^{\,j-1}$，故 $\sum 1/j! \le 2 + 1/2 + 1/4 + \cdots < 3$（实际上小于 $e \approx 2.72$）。

**再看单个结点的处理时间**：若还没放满 $n$ 行，`for` 循环依次尝试当前行的 $n$ 列；对每一列，计算两个对角线编号、检查三个数组、放置与撤销时修改标记，都是**常数时间**，所以处理这个结点需要 $O(n)$（递归内部的工作会在对应的**孩子结点**处另行计入）。若已放满 $n$ 行，复制并输出 `x[1..n]` 同样需要 $O(n)$。

> [!important] 总时间
> 访问至多 $O(n!)$ 个结点、每个结点花费 $O(n)$ 时间，**包含输出在内**的总时间上界为
> $$\boxed{\ O(n \cdot n!)\ }$$

### 2.6 几种时间界的比较

为了比较回溯算法中常见的几种时间界，需要几个基本极限（$a > 1$、$b > 0$ 为固定常数）：

$$\lim_{n\to\infty}\frac{n!}{n^n} = 0,\qquad \lim_{n\to\infty}\frac{a^n}{n!} = 0,\qquad \lim_{n\to\infty}\frac{n^b}{a^n} = 0$$

**证明思路**：

- **第一个**：把分式写成 $\prod_{i=1}^{n}(i/n)$，前 $\lfloor n/2\rfloor$ 个因子都不超过 $1/2$，其余不超过 1，故整个乘积趋于 0；
- **第二个**：数列 $a^n/n!$ 的后一项与前一项之比为 $a/(n+1)$，当 $n$ 足够大时不超过 $1/2$ ⟹ 趋于 0；
- **第三个**：相邻项之比为 $\dfrac{(1+1/n)^b}{a} \to \dfrac{1}{a} < 1$，可用等比数列估计 ⟹ 趋于 0。

> [!important] 增长速度的层级
> **固定次数的多项式 < 固定底数的指数 < 阶乘 < $n^n$**

需要更精确的阶乘估计时，用**斯特林公式**：

$$n! \sim \sqrt{2\pi n}\left(\frac{n}{e}\right)^{n}$$

## 3. 收费公路重建问题

**问题（turnpike reconstruction problem）**：一条笔直公路上有若干出口，有人测出了**每两个出口之间的距离**，却没有记下每个距离对应哪两个出口。能否只根据这些距离还原出口位置？

**例**：六个出口位置为 $0, 3, 5, 6, 8, 10$（千米），共 $\binom{6}{2} = 15$ 个距离，从小到大排列得

$$D = \{1, 2, 2, 2, 3, 3, 3, 4, 5, 5, 5, 6, 7, 8, 10\}$$

任务就是**已知 $D$，反推出口位置**。

两点说明：

1. 同一距离可能出现**多次**（$0\leftrightarrow3$、$3\leftrightarrow6$、$5\leftrightarrow8$ 的距离都是 3）⟹ $D$ 是**多重集**；
2. **整体平移不改变任何距离**，因此固定**最左出口为 0**，只求其余出口相对于它的位置。

### 3.1 基本事实

- 若有 $n$ 个不同出口，输入就有 $n(n-1)/2$ 个正距离。距离个数不符合此形式、或出现非正距离 ⟹ **直接判定无解**。
- 本例由 $n(n-1)/2 = 15$ 得 $n = 6$。
- **最大距离一定来自最左、最右两个出口** ⟹ 记最大距离为 $W$，两端位置就是 $0$ 和 $W$。本例 $W = 10$，放好两个端点后从 $D$ 中**扣去一份 10**。

### 3.2 关键引理：下一个位置只有两个候选

此时剩余最大距离为 8。只需尝试两个位置：

$$8 \quad\text{和}\quad 10 - 8 = 2$$

前者到左端点 0 的距离为 8，后者到右端点 10 的距离为 8。一般地，**若剩余最大距离为 $d$，候选位置就是 $d$ 和 $W-d$**。

> [!important] 为什么最大剩余距离一定能对应到一个端点
> 对尚未确定的点（图中是 8）：
> - 它到**左侧任意一点**的距离都**不超过**它到 0 的距离；
> - 它到**右侧任意一点**的距离都**不超过**它到 10 的距离。
>
> 因此**至少有一个端点是离它最远的点**。在搜索的中间过程，已放好的点之间的距离都已扣除，剩余距离分为两种：**未放点到已放点的距离**、以及**两个未放点之间的距离**。只要当前已放点的位置没选错，就可以对其余点继续用上面的观察：每个未放点到其他点的距离都不会超过它到某个端点的距离，而它到两端的距离也都还在集合中。**所以最大的剩余距离，一定出现在某个未放点与一个端点之间**——若是到 0 的距离，位置就是 $d$；若是到 $W$ 的距离，位置就是 $W-d$。

### 3.3 合法性检查

新点到**每个已放点**的距离都必须能在**剩余集合**中找到，而且**出现次数要足够**。形式化地：尝试位置 $y$ 时，计算

$$\Delta(y,X) = \{|y - x| : x \in X\}$$

并按**多重集**统计出现次数；若每种距离在 $D$ 中都有足够份数，就从 $D$ 扣去这些距离、把 $y$ 加入 $X$，再递归寻找下一个点。若后续无法放完所有点，就**撤销**这次选择：移去 $y$，把刚才扣去的距离**原样加回**，再尝试另一个候选位置。

> [!note] 完整手工搜索过程（从 $X = \{0,8,10\}$ 出发）
> 1. 剩余最大距离为 7，候选位置 7 和 3。**先试点 7**：它到 $0,8,10$ 的距离分别为 $7,1,3$，都能扣去，剩下 $D = \{2,2,3,3,4,5,5,5,6\}$。还缺两个点，最大剩余距离为 6 ⟹ 下一步只能试 6 或 4。放点 6 需要它到点 7 的距离 1，但清单中**已经没有 1**；放点 4 时它到 0 和 8 的距离**都是 4，需要两份 4，清单中却只有一份**。两个候选都失败 ⟹ **先放点 7 这条路走不通**。
> 2. **撤销点 7**，把距离 $7,1,3$ 加回 $D$，恢复到放点 7 之前的状态。**改试点 3**：它到 $0,8,10$ 的距离为 $3,5,7$，扣去后得 $X = \{0,3,8,10\}$，$D = \{1,2,2,3,3,4,5,5,6\}$。
> 3. 继续放点 6（最大剩余距离为 6，候选 6 和 4）。**先试 6**：它到 $0,3,8,10$ 的距离分别为 $6,3,2,4$，均可扣去 ⟹ $X = \{0,3,6,8,10\}$，$D = \{1,2,3,5,5\}$。
> 4. 最后放点 5：最大剩余距离为 5，两个候选位置 5 和 $10-5$ **重合**，只需尝试一次。点 5 到 $0,3,6,8,10$ 的距离分别为 $5,2,1,3,5$，**恰好用完所有剩余距离**。
>
> 六个点全部放好，得到解 $\{0,3,5,6,8,10\}$，与开头给出的布局一致。

### 3.4 算法

按**从左到右**的顺序，用数组 $X[1..n]$ 保存各点位置。调用递归过程前先令 $X[1] = 0$、$X[n] = W$，从 $D$ 中扣去一份 $W$，然后调用 `Reconstruct(X, D, n, 2, n-1)`（若输入为空则只有一个点，直接取 $X[1] = 0$）。

```text
Reconstruct(X, D, n, left, right):
   ▷ 已确定的两段坐标 X[1..left-1]、X[right+1..n]，以及剩余距离 D
1:  Found ← false
2:  if D 为空 then return true
3:  Dmax ← Find_Max(D)
4:  OK ← Check(Dmax)                    ▷ 检查位置是否合法、所需距离份数是否足够
5:  if OK then
6:      X[right] ← Dmax
7:      for i = 1, …, left-1  do Delete(|X[right] - X[i]|, D)
8:      for i = right+1, …, n  do Delete(|X[right] - X[i]|, D)
9:      Found ← Reconstruct(X, D, n, left, right-1)
10:     if ¬Found then                  ▷ 失败则把扣掉的距离原样加回
11:         for i = 1, …, left-1  do Insert(|X[right] - X[i]|, D)
12:         for i = right+1, …, n  do Insert(|X[right] - X[i]|, D)
13: if ¬Found then                       ▷ 尝试另一个候选位置 X[n] - Dmax
14:     OK ← Check(X[n] - Dmax)
15:     if OK then
16:         X[left] ← X[n] - Dmax
17:         for i = 1, …, left-1  do Delete(|X[left] - X[i]|, D)
18:         for i = right+1, …, n  do Delete(|X[left] - X[i]|, D)
19:         Found ← Reconstruct(X, D, n, left+1, right)
20:         if ¬Found then
21:             for i = 1, …, left-1  do Insert(|X[left] - X[i]|, D)
22:             for i = right+1, …, n  do Insert(|X[left] - X[i]|, D)
23: return Found
```

### 3.5 时间开销

**存储距离表**：用**平衡搜索树**保存每种距离及其**剩余份数**。不同距离至多有 $O(n^2)$ 种，查找、插入、删除一份距离、取得最大距离都可以在 $O(\log n)$ 时间内完成。

**一次尝试**：至多涉及 $n-1$ 个距离，因此检查、扣除、失败后的恢复共需 $O(n\log n)$ 时间。

**搜索树规模**：两端点固定后还需放置 $n-2$ 个点，故搜索树深度至多为 $n-2$，且**每次调用至多尝试两个位置**，因此结点数至多为

$$1 + 2 + \cdots + 2^{\,n-2} = O(2^n)$$

把每个结点的处理时间相加，再计入建立距离表的 $O(n^2\log n)$ 时间，得到总时间上界

$$\boxed{\ O\big(n^2\log n + n\log n \cdot 2^{\,n}\big)\ }$$

> [!warning] 仍然是指数级
> 实际搜索中 `Check` 会排除一部分候选位置，但**上述最坏情况分析仍然是指数级的**——回溯法不改变问题的难度，只是通过剪枝**大幅减少**常数与分支。

## 4. 回溯的一般框架与搜索顺序

### 4.1 一般写法

设一个解由 $n$ 次选择 $x_1,\dots,x_n$ 组成，$S_i$ 是第 $i$ 次选择的**候选集合**，$R$ 是题目要求满足的条件。调用 `Backtracking(i)` 时，前 $i-1$ 次选择已经确定，接下来逐一尝试 $S_i$ 中的候选值：

- 若 `Check` 发现当前选择**违反条件** ⟹ 跳过；
- 否则**先执行**这个选择，再**递归**确定第 $i+1$ 次选择；
- **递归失败** ⟹ 撤销本次选择，继续尝试下一个候选值；
- **递归成功** ⟹ 保留答案，**直接逐层返回**。

```text
Backtracking(i):               ▷ 前 i-1 次选择已确定
1:  Found ← false
2:  if i > n then return true
3:  for 依次取 x_i ∈ S_i do
4:      OK ← Check((x_1, …, x_i), R)
5:      if OK then
6:          执行选择 x_i，更新相应状态
7:          Found ← Backtracking(i + 1)
8:          if ¬Found then Undo(i)        ▷ 恢复到只确定前 i-1 次选择的状态
9:      if Found then break              ▷ 找到一解就停止，不再枚举其余候选
10: return Found
```

> [!note] 这个框架同时覆盖了前面两个例子
> - 八皇后：$S_i$ 是第 $i$ 行的 $n$ 个列，`Check` 查三个布尔数组；
> - 收费公路：$S_i$ 是最多两个候选位置，`Check` 查距离多重集的份数是否足够。

### 4.2 变量的选择顺序会影响工作量

上面的算法每次确定一个变量 $x_i$，再递归确定 $x_{i+1}$。**如果这些变量可以按任意顺序确定，先选哪一个会不会影响搜索的工作量？**

**例**：枚举三个变量的取值组合，其中 $a \in \{1,2\}$、$b \in \{1,2,3\}$、$c \in \{1,2,3,4\}$（暂不做剪枝）。

| 顺序 | 根 | 第 1 层 | 第 2 层 | 叶子 | 合计 |
|---|:--:|:--:|:--:|:--:|:--:|
| **先 $a$、再 $b$、最后 $c$** | 1 | 2 | 6 | 24 | $\mathbf{33}$ |
| **先 $c$、再 $b$、最后 $a$** | 1 | 4 | 12 | 24 | $\mathbf{41}$ |

两种顺序枚举的**完整组合完全相同**（都是 24 个），但**中间需要处理的结点数不同**：上图只有 $2+6 = 8$ 个，下图有 $4+12 = 16$ 个。

> [!important] 启发式规则：先选候选值少的变量
> **先处理候选值较少的变量，可以减少这类中间结点的数量。**
>
> 实际回溯还会根据约束排除不合法的取值，因此也常**优先确定当前合法候选值较少的变量**。例如：某个变量已经**没有任何合法取值**，就能**立即判定当前分支无解**——这正是「最小剩余值(MRV)」启发式的思想。

## 5. 博弈：极小极大与 α-β 剪枝

以**井字棋(tic-tac-toe)** 为例：$3\times3$ 棋盘，两人轮流在空格中画圈或画叉，先在一行、一列或一条对角线上连成三个相同符号的一方获胜；棋盘填满而双方都没连成三个则**平局**。

### 5.1 博弈的基本概念

- **博弈**：结果由**多个参与者的选择共同决定**的问题；
- **策略**：规定每一种轮到自己行动的局面下该怎样落子；
- **效用(utility)**：用数值表示对结果的偏好。设计算机获胜、平局、失败的效用为 $+1, 0, -1$，**人类的效用取相反数**。于是计算机希望分数尽量大、人类希望分数尽量小，双方效用之和**始终为 0** ⟹ **零和博弈**。

### 5.2 博弈树

假设当前轮到计算机，以当前局面为根：

- 为计算机的每一种合法落子建立**一个孩子**；
- 接下来轮到人类，再为人类的每一种应对建立下一层孩子；
- 如此**交替展开**直到游戏结束，就得到一棵**博弈树**；
- 每个叶子对应一种结束的局面，按计算机获胜 / 平局 / 失败分别标上 $+1, 0, -1$。

### 5.3 极小极大（minimax）策略

> [!important] 出发点
> 假设计算机有两种落子选择：选第一种后计算机**有可能赢**，但人类也有可能选择让计算机输的策略；选第二种后计算机**至少能保住平局**。
>
> **即使第一种也有获胜的可能，计算机仍应选择第二种**——因为**不能把希望寄托在对手犯错上**。
>
> 因此 minimax 认为：**人类总是会选择最小化（min）计算机效用的策略**，而计算机在这一前提下选择**最大化（max）自己效用**的策略。

**例**：

- 计算机选 A：人类可在 $+1$ 与 $-1$ 中选择，计算机认为人类会取 $-1$；
- 计算机选 B：计算机认为人类会在 $0$ 与 $+1$ 中取 $0$；
- 于是比较 A 对应的 $-1$ 与 B 对应的 $0$ ⟹ **选择 B，保证至少平局**。

> [!note] 为什么要假设对手会选择最不利于我们的决策
> - **直观**：这是零和博弈，对手的利益与我们的利益**完全相反**，因此对手的最优策略就是让我们最不利的策略；选 minimax 至少不会「输得太惨」；
> - **理论**：零和博弈的 minimax 策略实际上是双方的**纳什均衡(Nash equilibrium)**。

### 5.4 搜索深度与启发式估值

上面的做法要**一直搜索到游戏结束**才能给叶子评分。对国际象棋、围棋这类复杂游戏，后续对局太多，**无法在合理时间内搜索到终局**。

**对策**：只搜索到**一定深度**，遇到未结束的局面就用**启发式估值函数**打分。

> [!note] 井字棋的估值函数
> 获胜需要占满一行、一列或一条对角线，棋盘上共有**八条**这样的直线。若某条线上**已经有了对方的棋子**，自己就无法再通过这条线获胜。因此统计双方各自还剩多少条**没有被对方占用**的直线，用数量差衡量局面：
>
> 记局面 $P$ 中不含人类棋子的直线数为 $W_C(P)$、不含计算机棋子的直线数为 $W_H(P)$，取
> $$f(P) = W_C(P) - W_H(P)$$
>
> 按这个估值，**计算机可用的直线比人类多则分数为正**，少则为负。
>
> **例**：人类的叉位于上边中间 ⟹ 经过这个格子的**第一行**和**第二列**都不能再由计算机占满，故 $W_C = 8 - 2 = 6$；计算机的圈位于中心 ⟹ 经过中心的**一行、一列和两条对角线**都不能再由人类占满，故 $W_H = 8 - 4 = 4$。于是 $f(P) = 6 - 4 = 2$，表示计算机在这个局面下比人类有更多的获胜机会。

**总体做法**：基于这一思想展开**部分博弈树**，用启发式函数对（人为截断的）叶子评分，再用 minimax 策略选择下一步。

### 5.5 α-β 剪枝

在遍历博弈树计算 minimax 策略的过程中，**不一定需要遍历所有分支**。把轮到计算机的结点记为 **MAX**、轮到人类的结点记为 **MIN**。

> [!important] 两种剪枝
> **α 剪枝**（在 **MIN** 结点处）：根是 MAX，左孩子的值已算出为 **44**。右孩子是 MIN，刚算出它的一个孩子值为 **40**，就能知道它最终的值**至多为 40**——后面即使出现更大的值，MIN 仍会选择 40；如果出现更小的值，它只会更低。因此根一定可以选择左边的 44，**无需继续搜索右侧 MIN 的其他孩子**。
>
> **β 剪枝**（在 **MAX** 结点处）：根是 MIN，左孩子的值已算出为 **44**。右孩子是 MAX，只要找到一个值为 **68** 的孩子，就能保证它最终的值**至少为 68**。根要取较小值，已经有了 44，就**不必再算右侧 MAX 的其他孩子**。

**命名与语义的统一**：记 $\alpha$ 为当前路径上 **MAX 已能保证的最好值**（下界），$\beta$ 为 **MIN 已能保证的最好值**（上界）。当 $\alpha \ge \beta$ 时继续搜索已无意义：

- 在 **MIN 结点**，若其当前值 $\le \alpha$ ⟹ **α 剪枝**（MIN 不会再选这个分支，MAX 已有更好的选择）；
- 在 **MAX 结点**，若其当前值 $\ge \beta$ ⟹ **β 剪枝**。

> [!tip] 与其它方法的联系
> - α-β 剪枝中「**用上下界排除分支**」的思想，正是整数规划的**分支定界(branch-and-bound)** 法的基本思想；
> - 另一种应对巨大搜索空间的办法是**随机模拟**：对每个候选着法，按事先选定的策略**模拟多局**后续对局，计算**平均收益或获胜比例**，再据此比较着法——这是**蒙特卡罗方法**在博弈中的一种应用。

> 图 6.7 是上面两种剪枝的最小示意；图 6.8 是一棵较大的博弈树，图中每个数字都是完整 minimax 搜索算出的值，**灰色虚线标出 α-β 剪枝会跳过的部分**。建议对照 [[讲义/lec06_回溯法.pdf|lec06 讲义]] 把这棵树手算一遍，验证每处剪枝都符合上面的定义。

## 6. 习题与提示

> [!note] 习题 6.1（五皇后的角点）
> 在五皇后的所有合法摆法中，至少有一个皇后位于棋盘角点的摆法有几种？

**答案：8 种。**

先数**左上角 $(1,1)$** 放有皇后的摆法，得到 $(1,3,5,2,4)$ 和 $(1,4,2,5,3)$ 两种。将棋盘**旋转**可以把左上角移到其他任意一个角点，所以每个角点对应的解数都为 2，并且**不会重复**。因此总数为 $4 \times 2 = 8$。

> [!note] 习题 6.2（闭合马巡游）
> 在 $B \times B$ 棋盘上，马从 $(R,C)$ 可以跳到 $(R',C')$，当且仅当 $(|R-R'|, |C-C'|) \in \{(2,1),(1,2)\}$。一次**闭合马巡游**要让马恰好访问每个方格一次，并在访问最后一个方格后**再跳回起点**。
>
> 1. 为什么 $B$ 为奇数时不存在闭合马巡游？
> 2. 怎样用回溯法寻找闭合马巡游？除了检查方格是否访问过，还可以用哪些必要条件剪枝？

**答案**：

**1.** 把棋盘按 $R+C$ 的**奇偶性**涂成黑白两色。马每跳一步，**一个坐标改变 1、另一个改变 2**，因此 $R+C$ 的奇偶性**改变**，落点颜色也随之改变。闭合马巡游沿着黑、白交替的方格**回到起点**，所以经过的黑格与白格必须**一样多**。若 $B$ 为奇数，两种颜色的方格数**相差 1**，无法在各访问一次后回到起点 ⟹ **奇数边长的棋盘不存在闭合马巡游**。

**2.** 把棋盘变成一张**无向图**：每个方格对应一个顶点，一步马跳可以到达的两个方格之间连边。要找的是经过**全部顶点、每个顶点恰好一次**的**环**（起点可任取为 $s$，因为这样的环一定也经过 $s$）。两个剪枝原则：

- 若「**未访问顶点 + 起点**」构成的图**不连通** ⟹ 无法形成环；
- 若某个未访问顶点在**剩余图中不足两个邻点** ⟹ 无法进入后再离开它。

> [!note] 习题 6.3（重建与唯一性）
> 考虑距离多重集 $D = \{1,2,2,3,3,4,5,6,6,8\}$，固定最左点为 0。能否找到包含点 3 的解？包含点 5 的解？据此说明固定左端点后解是否一定唯一。另外，如果搜索过程中**没有因为后续失败而撤销已经放好的点**，使用 AVL 树保存距离时，为什么可以在 $O(n^2\log n)$ 时间内完成重建？

**答案**：

- 一个解是 $\{0,2,3,6,8\}$，**包含 3**；把这个点集**左右翻转**（每个坐标 $x \to 8-x$）得 $\{0,2,5,6,8\}$，**距离不变**，所以也有**包含 5** 的解。
- **这说明固定左端点后，解不一定唯一**（镜像对称是主要原因）。

**复杂度**：已经放好 $k$ 个点时，一个候选位置需要检查到这 $k$ 个点的距离；至多检查**两个**候选位置，再扣除选中位置所需的距离，共有 $O(k)$ 次距离操作。把各层工作相加得 $O(1 + 2 + \cdots + (n-1)) = O(n^2)$ 次操作；用 **AVL 树**保存距离时每次操作 $O(\log n)$，加上建立距离表的时间，总计 $O(n^2\log n)$。

> [!note] 习题 6.4（剪枝条件）
> 对讲义图 6.9 中的两棵博弈树，均按**从左到右**顺序搜索，$b$ 为实数，$d$ 是右侧尚未访问的内部结点。求使以 $d$ 为根的整棵子树被剪去的 $b$ 的取值范围。

**答案**：**上图 $b \ge 65$，下图 $b \le 68$。**（对照讲义图 6.9 的层次：上图自上而下为 MIN、MAX、MIN、叶子；下图为 MAX、MIN、MAX、叶子。）

> [!note] 习题 6.5（策梅洛定理）
> 在任何**博弈树有限**、具有**完全信息**、结果为**胜 / 负 / 平**的**确定性双人零和博弈**中，以下三种情况**恰好有一种**成立：（1）先手能保证获胜；（2）后手能保证获胜；（3）双方各自都有能保证**不输**的策略。请在井字棋的背景下证明。

**证明**：从任意合法局面出发，井字棋都**至多再下九步**就会结束，所以可以用 minimax 从**终局逐层向上**计算。仍把计算机获胜、人类获胜、平局分别记为 $+1,-1,0$。

- 若值为 $+1$：在 **MAX 结点**，最大值为 $+1$，**至少有一个孩子**也是 $+1$，计算机就选择它；在 **MIN 结点**，最小值为 $+1$，**所有孩子都只能是 $+1$**，人类无论怎么选都无法改变这个值。这样一直走到终局，分数仍为 $+1$ ⟹ **计算机（先手方）能保证获胜**。
- 若值为 $-1$：同理，人类在 MIN 结点选择值为 $-1$ 的孩子，而值为 $-1$ 的 MAX 结点的**所有孩子也都为 $-1$** ⟹ **人类能保证获胜**。
- 若值为 $0$：同样可以构造出**双方都能保证不输**的策略。

**三种情况互不重叠**也是显然的：一方有必胜策略时，另一方**不可能**有保证不输的策略，反之亦然。故恰好有一种成立。∎

## 7. 考点速查

1. **回溯 = 暴力搜索 + 剪枝**；剪枝的依据是「**当前部分解已经违反约束，后续无论怎么填都无法补救**」。
2. 算法设计的两个核心要求：**有效性**（结果正确/在近似比内/以一定概率合理）、**有效率**。
3. **八皇后对角线判据**：$|x_i - x_j| = |i - j|$。
4. **三个布尔数组**：`col[c]`、`diag1[r-c+n]`（左上→右下，$r-c$ 不变）、`diag2[r+c]`（右上→左下，$r+c$ 不变）。**$r-c$ 可能为负，故 $+n$ 变成下标**。
5. **回溯必须撤销**：各层共用同一组标记数组，所以**尝试完一个位置后要恢复标记**（第 10、11 步）。
6. **八皇后时间**：深度 $r$ 层结点数 $\frac{n!}{(n-r)!}$，总访问 $N < 3n!$ 个结点，每结点 $O(n)$ ⟹ $O(n\cdot n!)$。
7. **增长速度层级**：多项式 < 指数 < 阶乘 < $n^n$；斯特林公式 $n! \sim \sqrt{2\pi n}(n/e)^n$。
8. **收费公路**：$n(n-1)/2$ 个正距离 ⟹ $n$；最大距离 $W$ 确定两端；**剩余最大距离 $d$ 的候选位置只有 $d$ 和 $W-d$**。
9. **收费公路的合法性检查**：新点到**所有已放点**的距离必须在剩余多重集中**有足够份数**；失败要**原样加回**。
10. **收费公路时间**：平衡树存距离表 + 每结点 $O(n\log n)$ + 搜索树 $O(2^n)$ ⟹ $O(n^2\log n + n\log n\cdot 2^n)$。
11. **回溯通用框架**：`Check` → 选择 → 递归 → 失败则 `Undo`；**找到一解就 break**（若只要一解）。
12. **搜索顺序影响工作量**：先选**候选值少**的变量；典型例子 33 个结点 vs 41 个结点。
13. **零和博弈**的效用之和为 0；**minimax** 假设对手总是选择让我们最不利的策略（就是纳什均衡）。
14. **估值函数**用于只展开到一定深度的博弈树；井字棋用「未被对方占用的直线数之差」。
15. **α 剪枝**发生在 **MIN** 结点（当前值 $\le \alpha$，即 MAX 已有更好的选择）；**β 剪枝**发生在 **MAX** 结点（当前值 $\ge \beta$，即 MIN 已有更好的选择）。
16. α-β 的思想与**分支定界**同源；应对巨大搜索空间的另一条路是**蒙特卡罗随机模拟**。
