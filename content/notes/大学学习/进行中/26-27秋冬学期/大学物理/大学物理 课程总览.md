## 对原讲义的修订记录

为保正确，转换时对原讲义做了以下修订（均已核实）：

| 位置 | 原文 | 修订 |
|---|---|---|
| 电磁学 · 麦克斯韦方程组 | 电场高斯定理的积分形式写串行了 | 改为 $\oint\bm{D}\cdot\mathrm{d}\bm{S} = \sum q_i = \iiint\rho\,\mathrm{d}V$ |
| 电磁学 · 磁场能量 | 能量密度分母误写为 $\mu_0\mu$ | 改为 $u_m = \dfrac{B^2}{2\mu}$ |
| 光学 · 半波损定义 | 括号里方向写反（光密→光疏） | 更正为**光疏→光密**反射时有半波损 |
| 光学 · 垂直入射薄膜 | 「有半波损失」与「无半波损失」两情形的 $\delta$ 公式写反 | 有半波损 $\Rightarrow \delta = 2n_2e + \frac{\lambda}{2}$ |
| 光学 · 劈尖条纹间距推导 | `\dfrac{k+1}{2}lambda` 丢了反斜杠 | 改为 `\lambda` |
| 光学 · 牛顿环明纹半径 | $\sqrt{(2k - \frac12)R\lambda}$（根号内多乘 2） | 改为 $\sqrt{(k - \frac12)R\lambda}$ |
| 量子 · 含时薛定谔方程 | 缺 $\partial\Psi/\partial t$、系数有误 | 改为标准形式 $i\hbar\frac{\partial\Psi}{\partial t} = [-\frac{\hbar^2}{2m}\nabla^2 + U]\Psi$ |
| 量子 · 错别字 | 「蒲县」「例子」（多处） | 改为「谱线」「粒子」 |
| 量子 · 玻尔轨道推导 | 库仑力中 $\varepsilon$ 漏下标 | 改为 $\varepsilon_0$ |

> [!note] 渲染说明
> - 原讲义用 `\oiint`（闭合曲面积分），Obsidian 的 MathJax 不支持，统一替换为 `\oint`；
> - 原讲义用 `\degree`（MkDocs 扩展），替换为标准 LaTeX 的 `^\circ`；
> - 插图全部下载到 `附件/大学物理/`（73 张，4.6 MB），宽度按原网页百分比换算成像素标注。
