## 章节脉络

```text
        ┌─ 01 概论与性能度量 ── 建立「性能」这套语言（后面每章都要用）
        │
        ├─ 02 数制、ALU 与运算器 ── 数据怎么表示、运算器怎么算
        │      └ 补码 → 全加器 → CLA → 乘除法器 → IEEE 754
        │
计算机组成 ├─ 03 RISC-V 指令系统 ── 软硬件的接口
        │      └ 寄存器约定 → 六种格式 → 分支/过程/访存/跳转
        │
        ├─ 04 处理器：单周期与流水线 ── 【核心】把指令变成硬件
        │      └ 单周期 CPU → 五级流水线 → 三类冒险及解决
        │
        └─ 05 存储层次：Cache 与虚拟内存 ── 弥合速度与容量的鸿沟
               └ Cache 三策略 → 写策略 → AMAT → 页表 → TLB
```

几条跨章的主线：

- **性能铁律** $\text{CPU time} = \text{IC} \times \text{CPI} / f$：01 建立，04 用它算流水线收益（CPI 与冒险），05 用它算 cache 停等（memory-stall cycles）。
- **「三大妥协」**：定长指令 vs 立即数位数（03）、周期长度 vs 流水线深度（04）、块大小 vs 缺失代价（05）。
- **Make the common case fast**：`x0` 寄存器、立即数寻址（03）、前递（04）、Cache（05）都是它的具体化。

## 复习顺序建议

1. **先吃透 01 的性能铁律**——它是后面所有计算题的公式来源。
2. **03 的指令格式表优先硬背**（六种布局 + 立即数拼接），这是唯一「不背就做不了题」的部分。
3. **04 是全课重点**：单周期数据通路要能默画并标出各指令路径；流水线的三类冒险要能说清「为什么」「插几个 bubble」「条件怎么写」。
4. **05 的计算题最多**：直接映射的地址划分、AMAT、stall cycles 三类题必须练熟。
5. 02 内容多但套路固定（乘除法器流程 + IEEE 754 六步），适合在理解 03/04 之后集中突破。
